# ボス撃破後の帰還口：金の魔法陣（2026年10月、ZIP gold_return_circle_v1）

## 変えたこと
- ボスを倒したあとに出る村への帰還口（`run.portal`）の見た目を、渦巻きから**金の魔法陣**に替えました。古い渦巻きは描きません。
  - 絵：`assets/rooms/gold-circle.png`（ZIP の 128px 版）。元の 64・96・128px と README は `assets/reference/gold_return_circle_v1/`。
  - 床の上・道具とキャラクターの下に描きます（たけは魔法陣より手前）。横長のまま、回転させません。
  - 幅は約1.3マス（`RD.GOLD_CIRCLE.w`、画面を見て調整できます）。中心はマスの中心。操作の判定は今までどおり1マス。
- **出現**：帰還口が開いたとき、0.45秒で透明→表示・0.8→1.0倍、金の粒が少し上る（読み込み直したときは最初から表示）。
- **待機**：2秒周期で不透明度0.7〜1.0の緩い明滅。小さな金の粒5個が上へ流れて消えます。大きな発光はありません。
- **帰る**（今の「帰還口」の確認はそのまま。「村へ帰る」を押したあと）：
  - 0〜0.25秒：魔法陣が明るくなる（金色を足す。白一色の点滅はしない）
  - 0.25〜0.65秒：たけを包む細い半透明の金・クリーム色の光の柱と上る粒。たけが薄くなる
  - 0.65〜0.95秒：黒へ暗転 → 今までの帰還の処理（`returnHome`）を**1回だけ** → 村で0.35秒かけて明るくなる
- 演出の間は入力を受けません（透明な覆いで画面の操作を止め、キーも受けない）。ゲームの時間（敵・満腹度・ターン）は進みません。
- 帰還の処理は演出の最後に1回だけ呼びます（描画ループからは呼ばない）。演出の途中で読み込み直しても、まだ帰っていないので帰還口の上に立ったままです（二重の報酬は起きない）。
