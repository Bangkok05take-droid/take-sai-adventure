# マスターヤナイとバラン：物語の決定事項（2026年10月23日）

ストーリー担当のチャットでまとめた物語（ヤナイとバランの過去〜裏ボス後）を軸に、ゲーム側で決まったことの記録。
『ダイの大冒険』の登場人物を使ったこのゲーム独自の設定。原作の設定で補わない。

## 確定（ゲームに反映済み）
- 名前：通常の戦いは「竜騎士バラン」（第4章・30階）、隠しダンジョン35階の全力のバランは「竜魔神バラン」。
- 竜魔神バランの報酬：ドラゴニックオーラの盾だけ（真魔剛竜剣・竜の紋章は出ない）。
- 竜騎士バランを倒したあとの台詞はなし。ミストバーンに連れ去られるムービーだけ。
- ヤナイの一人称は「わたし」（おじいさんではない。バランと同い年）。
- マスターヤナイの像は台詞なし。「〜街を守った英雄ヤナイ〜」とだけ出る（ヤナイは言葉を残さず、行動と背中で見せた人）。
- 隠しダンジョンは35階まで（36階より先は作らない）。

## 確定（今の実装のまま）
- ティウのうわさ「昔、マスターヤナイが川の向こうで何かなくしたらしい」は残す。
- 竜の紋章はアクセサリーだけ（お宝の竜の紋章はなし）。赤い橋の向こうに落ちている。理由は説明しない。
- 最終章：30階でバーン撃破 → ミストが連れ去る → 亀裂から31階 → 33階で若い肉体を返し、真大魔王と最終戦。撃破でバーン・ミストバーンとも退場、本編終了。クリア後も30階の亀裂は残り、隠しダンジョンへ。
- バランの登場ムービー（額の紋章が輝き、装具で力を抑える）。
- ワーンはヤナイの元恋人。封印後の平和な時代に二人は一緒にいた。
- 町は敵のアジトの上に作られ、やがてアユタヤという場所になった。村・仏塔の作り手や年月、紋章が橋の向こうにある理由は設定しない。
- バランの動機は強さを証明したいだけ。魔王軍は利用しているだけ。ミストバーンは謎のまま（封印を解いたバランへの恩義と、利用したい気持ちの微妙な関係）。
- 竜魔神バランとは、最初に会ったときはそのまま戦う。

## これから（ストーリー担当と作る・保留）
- 冒頭を短くして、すぐ遊べるように（説明はゲームを進めながら）。
- マスターヤナイの記録：全部作り直す（なくしてもよい）。今の文章は仮。
- 章ごとの台詞（出発・帰還・村人）を作り直して監修。町の人と話せるようにする。
- バランの日記（仮案）：街の事件・封印を解いたのがバランという真相を、後から明かす。
- 最初の討伐（若いヤナイとバラン）の見せ方。
- 竜魔神バランの再戦の仕様（ターン数の評価・報酬・何度でも戦えるか）、再訪時の猫。
- 町の見せ方（発展ムービー、図書館か木漏れ日の家か。モッちゃんを出したい）。
