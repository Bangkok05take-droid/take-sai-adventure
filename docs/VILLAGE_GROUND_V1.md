# 街の床 v1（2026年10月）

素材は `assets/village/ground/`（sandstone・brick・grass・earth、各128×128）に置きました。repeat-preview・manifest・描画例（ground-draw.mjs）は `assets/reference/village-ground-v1/` に、指示書は `docs/VILLAGE_GROUND_V1_INSTRUCTIONS.md` にあります。

## 描き方
- **写し方:** 128×128 は「32ドットの床4×4マス分」の連続した模様です。1マスに縮めず、地図のドット座標を128で割った余りの位置の色をそのまま写します。描画例の `mod4(worldTile)×32` と同じ考え方で、マスごとにランダムに切り出すことはしません。
- **模様は世界に固定:** 村の床は、地図全体を1枚の絵として作り（`js/village.js` の `paintGround`）、カメラの位置に合わせて整数倍で描きます。
  - カメラが動いても、地図上の同じ場所の模様は変わりません。
  - 確認したこと：幅360・390・430で、たけを1マス動かして画面をずらし、地図の同じマスの900画素を比べたところ、違いは0でした。
- **作り直し:** 床は村の状態が変わったとき（施設を建てたなど）だけ作り直します。素材の読み込みは最初に1回だけで、読み込めないときは今までのコードで描いた床に戻ります。
- **明暗は控えめに:** 模様の明るさの差を、平均の色へ寄せて弱めています（`TS.ASSETS.village.ground.textures` の割合）。石畳・レンガは72%、草・土は80%で、建物・人物・子供・猫が引き立つようにしています。夜の村では少し暗くします。

## 割り当て（今までの地形の種類のまま。通行の判定は変えていない）
| 地形 | 模様 |
|---|---|
| 中央広場・主な歩く道（p） | 砂岩の石畳 |
| 寺院への道・港沿いの道（b）・寺院の石段（s） | 赤茶のレンガ（石段は段の線を重ねる） |
| 草地・庭・向こう岸（g・f） | 草地 |
| 木の根元 | 土（草地の上だけ。ふちは市松に散らした平らな境目） |
| 水・桟橋・赤い橋・寺院の基壇 | 今までのまま |

- 縁石（草地との境の小さな段差）、参道の金色のふち、広場の紋章、岸壁は、今までどおり模様の上に描きます。
- 床 → 地面の小物・影 → 建物・人物の順番は変えていません。床が人物・猫の上に描かれることはありません。

## 素材の限界
- 4種類の基本の模様で、角や内角の組み合わせ（オートタイル）はありません。草地と道の境は、今までの縁石の線で区切っています。
- 繰り返しの継ぎ目は、実際の倍率（スマホで1ドット＝3ピクセル）で見て、石組み・レンガの目地が大きく途切れる所はありませんでした。完全に継ぎ目がないとは言えません。

## 改修前後の比較
`docs/village-ground-v1/` に、同じ村の状態・同じたけの位置・同じ画面の大きさで撮った「左：改修前／右：改修後」を置いています。
- 場所：広場・サイの店・像・鍛冶屋・展示室・倉庫・食堂・港
- 画面の幅：390（広場は360・430も）
- 撮り直し：`node tools/village-shots.js 出力フォルダ`
