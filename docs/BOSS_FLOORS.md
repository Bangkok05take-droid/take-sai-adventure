# 章ごとのボスの階（2026年10月）

## 配置

| 章 | ボス | ボスの階 |
|---|---|---|
| 第1章 | クロコダイン | 15階 |
| 第2章 | フレイザード | 20階 |
| 第3章 | キルバーン | 25階 |
| 第4章 | バラン | 30階 |
| 第5章 | ミストバーン | 30階（第4章とは別の探索） |
| 最終章 | 大魔王バーン → 真大魔王バーン | 35階 |

- **設定の場所**：`js/story.js` の `D.CHAPTERS[章].goal` です。`D.bossFloorOf(章)` と `G.maxFloor(探索)` は、すべてこの値を使います。
- **探索の流れ**：どの章も1階から始まります。ボスの階には階段がありません。倒すと報酬と帰還口が出て、村へ帰ると次の章へ進みます。
- **ボスの階の中身**：通常の敵、モンスターハウス、謎の旅商人は出ません。ボスが呼び出す敵（分身・魔界の小鬼など）はこれまでどおりです。
- **帰還の祠**：25階に1回だけ出ます。ただしボスの階には置きません。
  - 第1・2章：25階まで行かないので出ません。
  - 第3章：25階がボスの階なので出ません。
  - 第4章以降：25階に1回だけ出ます。
- **最終章**：これまでどおりです。1〜30階は通常の階、31〜34階は大魔王の城、35階で大魔王バーン → ミストバーン再登場の演出 → 準備 → 真大魔王バーンの順に進み、途中で村へは帰しません。

## 既存のセーブ（探索中だった場合）
- 探索には配置の版（`run.layout`）を記録します。新しく始める探索は `2`（上の配置）です。
- この更新の前に始めた探索には版の記録がありません。その探索は**以前の配置（第1〜5章のボスは30階）のまま最後まで進みます**。
  - 新しいボスの階より深くにいても、浅い所にいても、進めなくなることはありません。
  - 村へ帰った次の探索から、新しい配置になります。
- 章、撃破済みのボス、報酬の受け取り、所持品、倉庫、村の発展は変えていません。報酬は撃破済みの記録で判定するので、二重には出ません。

## 難しさの確認（数値は変えていない。調整案のみ）

### 確かめ方
- 簡易AI（ボスの予告をよけない）で、各章の初めから100回ずつボスの階まで進めました。
- 道中は倒れないようHPを補助し、経験値と拾う道具は通常どおりにしています。
- 出発時の装備は、第1章が「どうのつるぎ・木の盾」、第2・3章が「てつのつるぎ+2・てつの盾+2」です。
- その到着時の平均の強さで、ボスを倒すまでの攻撃回数と、ボスの通常攻撃で倒れるまでの回数を計算しました。

| ボス | 到着時（平均） | ボスを倒すまで | 倒れるまで（通常攻撃） |
|---|---|---|---|
| クロコダイン 新15階 | Lv13.6・HP106・攻20・防3 | 約71回 | 約3.3回 |
| クロコダイン 旧30階 | Lv25.6・HP177・攻32・防3 | 約32回 | 約5.5回 |
| フレイザード 新20階 | Lv18・HP132・攻29・防6 | 約39回 | 約4.2回 |
| フレイザード 旧30階 | Lv25.6・HP177・攻37・防6 | 約27回 | 約5.6回 |
| キルバーン 新25階 | Lv21・HP151・攻32・防6 | 約30回 | 約4.7回 |
| キルバーン 旧30階 | Lv24・HP168・攻35・防6 | 約27回 | 約5.3回 |

章のボスは階による強さの補正がない（固定の能力）ので、浅い階に置くとプレイヤーとの差がそのまま出ます。

### 結果
- **クロコダイン（15階）は明らかに強すぎます。** 倒すまでの回数が約2.2倍、倒れるまでの回数が約6割になります。
- **フレイザード（20階）はやや強めです。** 倒すまで約1.45倍、倒れるまで約3/4です。
- **キルバーン（25階）は、以前とほぼ同じです。**

### 調整案（未実施）
階の比率で一律に下げるのではなく、「以前の30階での戦いの手応え（倒すまで約30回、倒れるまで約5回）」に戻す値を、到着時の強さから逆算しました。予告・隙・床の危険などの行動はそのままにします。

- **クロコダイン**：HP 640→420、攻撃 34→22、防御 15→8。到着時の強さで計算すると、倒すまで約31回、倒れるまで約5.3回になります。
- **フレイザード**：HP 680→560、攻撃 36→30、防御 15→12。倒すまで約29回、倒れるまで約5.1回。炎と氷の床のダメージは攻撃に比例するので、一緒に下がります。

あわせて見直したほうがよい点：
- **第1章の報酬**：（2026年10月に変更済み）第1章の報酬の盾は第3章（キルバーン）へ移り「ファントムシールド」になりました。第1章の報酬はお宝「クロコダイルの涙」と黄金の象です（`docs/BOSS_REWARDS.md`）。
- **経験値**：クロコダインの経験値700は、Lv13ほどで得ると一気に数レベル上がります。

## ボス部屋の戦い（2026年10月）
ボスの階に着いただけでは戦いは始まりません。ボスは奥の大広間（ボス部屋）の中央で待ちます。

**戦いが始まる前**
- ボスは、移動・攻撃・特殊能力・呼び出し・予告をしません。通路からたけが見えても追いかけません。
- 曲は探索の曲のまま、ボスのHPバーも出ません。待っている間の見た目の動きはあります。
- 投げる・杖・ねむり草・どんそくの粉・雷鳴の巻物・体当たりでボスを攻撃しようとすると、効果をかける前に止めます。
  - 「部屋に入ってから戦おう」と表示します。
  - 道具はなくならず、杖の回数もターンも減りません。

**戦いが始まるとき**（`G.checkBossRoom`）
- 条件は、たけがボス部屋の中へ初めて入ったときです。部屋の範囲は地図の部屋の四角で、距離や見えているかでは決めません。
- 1回だけ、次のことが起きます。
  - ダッシュ・長押し・予約を止める。
  - 「○○との戦いが始まった！」と表示し、登場の会話を出す。
  - ボス戦の曲に切りかえ、ボスのHPバーを出す。
- 入ったターンには、ボスは動きません（入室直後の追い打ちはなし）。演出や曲の切りかえで、ボスが余分に動くことはありません。

**戦いの間**
- **移動の範囲:** ボスと、ボスが呼んだ手下・分身は、ボス部屋の中だけを動きます（`G.confined`）。
  - 歩く・突進・入れかわり（キルバーン）・呼び出す位置のどれも、部屋の外へは出ません。
  - ボスから伸びる直線の大技（突進・剣技・闇の糸・炎の鳥・滅びの炎）も、部屋の中までです。
- **床の印:** 炎・氷・罠・雷・魔界の炎は、通れる床のマスにだけ置きます。
- **たけが通路へ戻ったとき:** 入口は封鎖していないので、通路へ戻れます。
  - その間、ボスは入口に立ちふさがらず、部屋の中央へ戻ります（いつでも入り直せます）。
  - 戦いが始まった状態とボスのHPはそのままです。開始の表示はもう出ず、ボスの回復・作り直しもしません。曲もボス戦のままです。
- **最終章:** 大魔王バーンを倒したあとの準備から、真大魔王バーンを倒すまで、ボス戦の曲が続きます。
- **曲の切りかえ:** 倒すと探索の曲へ、倒れると曲を止めて村へ、帰還すると村の曲へ切りかわります。

**セーブ**（`run.bossFight`：部屋の四角・engaged・won）
- 開始前か、戦い中か、倒したかを保存し、読み込み直しても続きから再開します。
- この更新の前のセーブ（ボス戦の途中）は、読み込むときに状態を作ります（`js/save.js` の `fixBossFight`）。
  - **戦い中にする:** ボスが傷ついている、目を覚ましている、予告中、分身・手下や床の印がある、たけが部屋の中、最終決戦の途中のどれか。
  - **倒したあとにする:** ボスがもういないとき。
  - **ボスの位置:** 通路など部屋の外にいたら、たけと重ならない部屋の中の空いた床へ移します。
  - **変えないもの:** HP・報酬・撃破の記録は変えません。

**右端に「1」の枠が縦に並んでいた不具合**
- **原因:** ボスの部屋を「ボスが今いる部屋」で決めていました。ボスが通路へ出ると部屋が見つからず、代わりに地図の最後の部屋を使っていました。
  - フレイザードは通路から、まだ見ていない大広間いっぱいに炎の印（2列ずつのしま、数字は1）を置いていました。
  - 床の印は、見ていない場所にも描いていました。
  - その結果、暗い所に枠と数字だけが並んで見えました。
- **再現:** 20階でフレイザードが通路のたけを追ってきたとき。大広間の120マスに印があり、120マスすべてが未探索でした。
- **修正:**
  - ボスの部屋は、階を作ったときに決めた部屋に固定しました。ボスは部屋から出ません。
  - 床の印は、たけがすでに見た場所にだけ描くようにしました。
