# 通常ダンジョン7地域の背景（ZIP dungeon_7themes_art_v1）：レンガの回廊の組み込みプレビュー（2026年10月21日）

**本番はまだ今までの絵のまま**（`D.DUNGEON_ART` が空）。この確認の道具の間だけ、レンガの回廊を素材の絵に切り替えて撮っています。

## 今の作り（調べた結果）
- 1マス＝32×32ドット。マスは「床（部屋）」「床（通路・幅1マス）」「壁の正面（下が床の壁）」「壁の上面（それ以外の壁の塊）」の4種類を、探索で見えたときに1回だけ描く（`js/tiles.js`）。
- 地域は階で決まる（`D.themeOfFloor`）。レンガの回廊は1〜3階。ボスの階は各ボスの景観（今回は変えない）。

## 素材の使い方（プレビュー）
- 原画：`assets/reference/dungeon-7themes-v1/`（7枚。原寸・無加工のまま）。
- 切り出し：`python3 -I tools/make-dungeon-art.py brick` → `assets/dungeon/brick/`
| 部品 | 原画のどこ | ゲームでの使い方 |
|---|---|---|
| 床 floor_0〜2 | 1段目の床3枚（ふちの縁取りを約12px落とした内側） | 64×64＝**2×2マス**に縮め、マップ全体の偶数マスにそろえて敷く。柄は2×2マスごとに選ぶ。少し明るく・色を少し抑えた（原画のままだと敵や赤い予告が沈んだため）。通路は同じ絵を少し暗く |
| 飾り床 floor_deco | 1段目の4枚目（モザイク） | 切り出しただけ。まだ使っていない |
| 壁 wall_0〜1 | 2段目の横長の壁（アーチ2つ・たいまつ左／右） | 64×64＝**2マス幅・2マス高**。下の1マスを壁の正面、上の1マスをその上の壁に。壁の並びは左の端から数えて2マスずつ |
| 細い壁 narrow_0〜1 | 2段目の細い壁（アーチ1つ） | 32×64＝**1マス幅**。壁の正面が奇数マスで終わる最後の1マスと、1マスだけの壁に |
| 3段目の角・4段目の飾り（柱・火鉢・アーチ・がれき） | — | **使っていない**（角は斜めから見た絵で、このゲームの真上から見た地形に合わない。飾りは置き場所が決まっていない） |
- 描き方：今のコードの絵を描いたあとに、素材の絵を重ねる（`js/tiles.js` の `artOverlay`）。地図・当たり判定・通れる所は変えていない。壁の絵にたいまつが描かれているので、正面の壁の動くたいまつは出さない。

## 確認したこと（PCのブラウザ、幅360・390・430）
- `node tools/dungeon-art-preview.js brick`（9項目 OK）：2階で、同じ場所を「今の絵（before）」と「素材の絵（after）」で撮った。部屋の中央（攻撃の予告3×3と敵）・細い通路・部屋の左上と右下の角・床の道具。画像は `docs/dungeon-art-v1/brick/`（`*_compare_390.jpg` が左右に並べた比較）。
- 階全体：`overview_before.png`・`overview_after.png`、印つき `overview_marks.png`（`python3 -I tools/dungeon-art-marks.py brick`）。
- たけ・敵・宝箱・道具・赤い予告は、床を明るくしたあとは見分けられる。予告の赤は、今の白っぽい床よりは目立たない（必要なら予告の色を濃くできる）。
- スマホの実機ではまだ見ていない。

## 足りない素材（印つきの全体図 overview_marks.png）
| 印 | 場所 | 今の表示 | 欲しい素材 |
|---|---|---|---|
| 青い線（この階で91か所） | 部屋・通路の**左右の壁** | 今のコードの絵（レンガの塊＋細い縁） | 真上から見た、床に接する壁の縁（左向き・右向き）。1マス幅で縦にくり返せるもの |
| 紫の線（55か所） | 部屋・通路の**下側の壁**（上に床がある壁） | 今のコードの絵 | 真上から見た、床の下の縁（壁の上面のふち）。横にくり返せるもの |
| 黄色の点（29か所） | **角**（床の斜め向こうの壁の角） | 今のコードの絵 | 角の部品（外側の角・内側の角、4方向）。**真上から見た絵**（今の3段目は斜めから見た絵で合わない） |
| （全体の背景） | **壁の上面**（壁の塊・部屋の外） | 今のコードのレンガ | 真上から見た壁の上面（天井）。継ぎ目なしでくり返せるもの |
| 橙の枠（7か所） | 1マス幅の細い壁を使った所 | 素材の細い壁 | 今のままでよいか見てください（2マス幅の壁と並ぶ所の継ぎ目） |
- 床：2×2マスごとに石の縁（目地）が出るので、2マスおきの格子が少し見える。継ぎ目のない床（どこで切ってもつながる）があると、より自然になる。
- 欲しい大きさの目安：**1マス＝128ドット**（ゲームでは32ドットに縮める）。床・壁の上面は 256×256（2×2マス）で上下左右につながるもの。壁の縁・角は 128×128 の1マス単位。

## 次の進め方
- 足りない素材が届いたら、レンガの回廊で縁・角・上面を組み込んで、本番（`D.DUNGEON_ART.brick = true`）にするか判断していただく。
- 同じやり方で残る6地域へ。README の新しい階の割り当て（7〜14階を「地下の遺跡」、21〜24階を「地底の古代神殿」など）は、今の地域の分け方（7〜10階 水の神殿・11〜15階 地下庭園・21〜25階 水晶の地下神殿）と違うので、地域を組み込むときに合わせて変える（地域の名前・敵の出現表は変えない）。
