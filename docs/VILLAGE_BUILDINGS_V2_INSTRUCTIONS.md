# 村の施設4点 差し替え v2
今回の範囲は鍛冶屋・食堂・倉庫・展示室の外観。サイの店の仕上がりに合わせる。
blacksmith.png 鍛冶屋 / eatery.png 食堂 / warehouse.png 倉庫 / exhibition.png 展示室。
個別PNGは224x224透過。*-source.pngは切り出した高解像度原画。manifest.jsonとpreview.png同梱。
内蔵画像生成で制作し透過抽出と最近傍縮小を行った素材。手打ちピクセル素材ではない。切り出し・透明背景・縮小一覧を確認済み、ゲーム表示と実機スマホは未検証。

## 組み込み
既存コードの施設ID・描画範囲・入口・施設メニュー呼出し・進行フラグを確認する。サイの店の表示倍率と人物に対する扉の大きさを基準に4施設を合わせる。224pxをそのまま画面224CSSpxと決めつけない。
旧外観と新画像を二重描画しない。金床・炉・テーブル・木箱等は画像に含まれるため、旧小物や旧炎の位置が不自然なら描画を調整する。炎アニメを残す場合は新しい炉の口に正しく合わせる。煙は新画像の煙突に合わせる。
食堂の入口は左寄り。絵の足元アンカーは入口位置ではない。既存のアクセス経路と施設操作が成立するよう個別に入口・操作範囲を合わせる。
PNGの透明領域を含む矩形全体を障害物やクリック領域にしない。建物本体・前庭・店先の範囲を確認し、主人公が壁へ潜り込まず、屋根上へ不自然に出ない描画順にする。
看板は既存UIとして読みやすく表示。名前を画像へ焼き込まない。コイ・ワーンなど既存NPCは維持し、新外観の前に自然に配置する。
未解放・建設済み・再建中等の既存条件を維持し、新画像を入れた理由で施設を勝手に解放しない。機能・価格・強化値・所持品・寄贈・セーブ・章進行・音楽は変更しない。

## 検証
同じマップ位置で改修前後を撮影。360/390/430px幅で外観・NPC・看板・通路を確認。各施設の既存メニューを開き、施設操作と保存が維持されること。解放前後・旧セーブ再開も確認。ゲームで見た結果を根拠に、必要な描画サイズを調整する。
いつものブランチ claude/take-sai-adventure-game-loh1fe へコミットし通常プッシュ。変更範囲と確認結果・未確認を報告。
