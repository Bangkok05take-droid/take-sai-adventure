# 音楽（試作）：冒険のファンファーレ／マスターヤナイのテーマ

どちらもオリジナルの試作曲です。既存の曲の旋律・音源は使っていません。
WebAudio のプログラム音源で鳴らしています（`js/music.js`）。外部の音源やサービスは使っていません。

## ゲーム内で聴く
1. 村の右上の「≡」、またはダンジョンの「メニュー」を開く。
2. 「音楽試聴・音量」を押す。
3. 曲ごとの「▶ 再生」で聴く。「■ 停止」で止める。「ループのつなぎ目を聴く」を押すと、ヤナイのテーマを1周目の終わりの少し前から再生する。

- 試聴している間は時間（ターン）が進みません。
- 閉じると試聴は止まり、元の場面の音楽に戻ります。
- BGM と効果音の音量は、この画面で別々に変えられます（保存されます）。
- 「音：オフ」のときは鳴りません。

## 書き出した音声（確認用）
ゲームと同じ合成処理を `OfflineAudioContext` で書き出しました。モノラル 96kbps の mp3 です。
- `fanfare_preview.mp3`：ファンファーレ（約12秒。最後の消える音を含む）
- `yanai_theme_2loops_preview.mp3`：ヤナイのテーマを2周（約2分23秒）。約76秒の所が1周目から2周目へのつなぎ目。

## 曲の仕様
| 曲 | 長さ | BPM・拍子・調 | ループ | 楽器（すべてプログラム音源による「風」の近似） |
|---|---|---|---|---|
| 冒険のファンファーレ | 19拍＝約10.2秒＋余韻約1.8秒 | 112・4/4・変ロ長調 | しない | 金管風の主旋律（＋3度下の2番手）、低い金管風の和音、低音、ティンパニ風 |
| マスターヤナイのテーマ | 112拍＝約76.4秒 | 88・4/4・ヘ長調 | 17拍目（約10.9秒）〜112拍目を繰り返す（1周約65.5秒） | ホルン風の主旋律、弦風の和音（Bの前半は刻み）、木管風の合いの手、控えめな低音、小太鼓風 |

- **ファンファーレの構成**：上昇する分散和音（1小節）→ 覚えやすい主題（3小節）→ 主和音で着地して余韻で消える。
- **ヤナイのテーマの構成**：導入（4小節）→ 主題A（8）→ 展開B（8：ニ短調の哀愁から、上昇して希望へ）→ 主題Aの再提示（6：終わりを上向きに変えて希望を残す）→ ループへの接続（2）。
  - 接続の2小節は、導入の後半と同じ形（木管がモチーフをほのめかす）です。そのため、ループで主題Aの頭へ自然に戻ります。

## ヤナイのモチーフ（最終決戦用に残しておく）
主題Aの最初の2小節（ヘ長調）：

`C4(1拍) F4(1.5) G4(0.5) A4(1) | A4(0.5) G4(0.5) F4(1) D4(2)`

- 音階の度数は「5-1-2-3 | 3-2-1-6」。下から主音へ跳び上がって上る前半（決意）と、静かに降りる後半（優しさ）の組み合わせです。
- `js/music.js` の `YANAI_MOTIF`（曲のデータの `motif`）として残してあります。
- 最終決戦の曲は、まだ作っていません。

## 再生のしくみ
- **曲の選択と再生の分離**：曲の一覧（`TS.Music.LIBRARY`）と再生処理（`TS.Music.play`）を分けています。録音した音源に替えるときは、一覧に `file`（と `loopStart`／`loopEnd` 秒）を書くだけで、同じ `play()` でファイルを再生します。
- **予約のしかた**：0.1秒ごとに0.6秒先までの音を予約します。テンポは AudioContext の時計だけで決まるので、ダッシュや高速足踏みでは変わりません。
- **ループ**：ループ区間の終わりで予約位置を区間の頭へ戻すので、すき間はできません。
- **多重再生の防止**：一度に鳴る曲は1つだけです。再生のたびに前の曲を0.12秒でフェードして止めます。0.25秒以内の連打は1回にまとめます。
- **音の出口**：
  - 効果音 → 効果音の音量 → 全体のオン/オフ。
  - BGM・音楽 → BGMの音量 → 軽いコンプレッサー（音割れ防止）→ 全体のオン/オフ。
- **アプリが裏に回ったとき**：試聴を止め、音の処理を一時停止します。戻ると再開しますが、試聴は自動では再開しません（重複しない）。

## 確認したこと
- **自動テスト**（`tests/e2e.test.js` の「音楽試聴」）：再生、連打、曲の切り替え、停止、ループして2周目へ戻ること、ファンファーレが最後まで鳴って止まること、音量の保存、ミュート、裏に回したときの停止、閉じると元のBGMに戻ること、ターンが進まないこと。
- **書き出した音声の数値確認**：
  - ピーク：ファンファーレ -1.7dBFS、ヤナイ -2.3dBFS。音割れはありません。ゲーム内では全体の音量（0.6倍）がかかるので、さらに約4.4dB小さくなります。
  - 0.5秒以上の無音：曲の終わりの余韻のあとだけで、ループのつなぎ目にはありません。
  - 4kHz以上の成分：0.1%前後で、耳に刺さる高音はほとんどありません。

## 限界
- ホルン・金管・弦・木管・ティンパニ・小太鼓は、波形とフィルターで作った「それらしい」音です。本物の楽器の息づかい・弓の質感・ホールの響きは再現できていません（リバーブも付けていません）。
- 低音（約50〜90Hz）は、スマホのスピーカーではほとんど聞こえません。旋律と和音は 250Hz 以上にあるので聞こえる設計ですが、実機では確認していません。
- 書き出しの処理時間から見ると、ヤナイのテーマはこの検証環境（ソフトウェア処理のブラウザ）で実時間の約4倍の速さで描けます。スマホでの実際の負荷は未確認です。
