# 音楽（試作 第2版）

どれもオリジナルの試作曲です。参考にした曲の旋律や録音は使っていません。
WebAudio のプログラム音源で鳴らしています（`js/music.js`）。外部の音源やサービスは使っていません。
通常プレイのBGMはまだ置き換えていません。下の試聴画面で方向性を確認する段階です。

## ゲーム内で聴く
1. 村の右上の「≡」、またはダンジョンの「メニュー」を開く。
2. 「音楽試聴・音量」を押す。

- 「第2版（今回の試作）」の4曲と「第1版（比較用）」の2曲が並びます。曲ごとに「▶ 再生」で聴き、「■ 停止」で止めます。
- ループする曲には「つなぎ目」ボタンがあり、ループの8拍前から再生します。
- 試聴している間はターンが進みません。閉じると試聴が止まり、元のBGMに戻ります。
- BGM と効果音の音量は別々に変えられ、保存されます。「音：オフ」のときは鳴りません。

### 冒険のファンファーレ（作り直し）
- 1小節目から金管の合奏で始めます。均等な分散和音は使っていません。
- 「付点と休符の呼びかけ」と「下りて長く伸ばす応答」を2回くり返します。2回目は高く。
- 5小節目で♭VII の和音（明るく広がる響き）を通り、6小節目の主和音で大きく着地して余韻で消えます。
- 伴奏は毎拍刻みません。持続音と、和音が変わる所のティンパニ・シンバル、駆け上がる弦で盛り上げます。

### マスターヤナイのテーマ（明るく勇ましく改訂）
- 2小節の短い導入のあと、すぐ主旋律が入ります。
- 構成は、主題A → 主題A'（ホルンの和音つき）→ 短い橋B（ここだけ少し哀愁、すぐ上向きに）→ 主題A''（勝利）→ 接続（＝導入と同じ）です。
- 主旋律は中音域（実音でファ4〜ソ5）の金管合奏です。弦の8分の刻みと、規則正しすぎないよう飾りを入れた小太鼓で前へ進みます。

### 村の音楽（新規）
- 笛の主旋律のすき間に木琴が答え、Bでは2拍ずつ掛け合います。A'では役を入れかえ、木琴が主旋律、笛が答えます。
- Cは笛とクラリネットの3度の二重奏です。
- 高音は少なめにしました。主旋律はおもにレ4〜ソ5です。

### ダンジョンの音楽（新規）
- 短い旋律のあとに必ず休みを置いています。変ホ長調の和音（♭II）で影を付けました。
- 低弦の持続音の上で、ピチカートの足音が慎重に歩きます。
- 探索の主題は中音域（ファ4〜レ5）に置き、スマホのスピーカーでも聞こえるようにしました。
- 大きな音、鋭い高音、急な強弱は使っていません。

## ヤナイのモチーフ（最終決戦用）
主題Aの最初の2小節です。ハ長調で記譜していて、実際の音は2半音下（変ロ長調）です。

`G4(付点8分) C5(1.25拍) D5(8分) E5(8分) G5(4分) | A5(付点8分) G5(16分) F5 E5 D5(付点4分)`

- 第1版のモチーフの頭（音階の 5-1-2-3）を残しました。それを付点で力強くし、さらに5度上まで駆け上がる形に発展させています。
- `js/music.js` の `YANAI_MOTIF`（第1版は `YANAI_MOTIF_V1`）に記録しています。
- 最終決戦の曲は、まだ作っていません。

## 音作りで変えたこと（第2版）
- **金管**：ずらした2本ののこぎり波にしました。出だしでわずかに音程がしゃくり上がり、強く吹くほどフィルターが開きます。ビブラートは主旋律だけです。
- **弦**：ずらした2本の合奏と、短い刻み（スピッカート風）、ピチカート、低弦を分けました。
- **木管・打楽器**：笛（吹き始めの息つき）、クラリネット、木琴、小さな鐘、太鼓、タンバリン、拍子木、チン、シンバルを加えました。
- **残響**：作った残響を曲ごとの深さで足しています（ダンジョンは深め、村は浅め）。
- **音量**：全体の音量は第1版と同じくらい（平均 -14〜-18dB）にそろえました。旋律が聞こえにくい所は、伴奏を下げて対応しています。

## 確認したこと
**書き出した音声の数値確認**（ループする曲は2周分）

| 曲 | ピーク | 音割れ | つなぎ目の無音 | 主旋律と伴奏の差（300〜3000Hz、中央値） |
|---|---|---|---|---|
| ファンファーレ | -2.0dBFS | なし | ループしない | +2.3dB（主旋律が上回る時間 82%） |
| ヤナイ | -2.7dBFS | なし | なし | +4.7dB（96%） |
| 村 | -3.0dBFS | なし | なし | +7.5dB（83%） |
| ダンジョン | -4.7dBFS | なし | なし | +9.6dB（86%） |

- 5kHz 以上の成分はどの曲も0.1%未満です。
- 村の音楽で0.1秒の間に大きく上がる所は、太鼓の打点です。
- **動作の自動テスト**：曲の一覧、連打、曲の切り替え、停止、ループする3曲がつなぎ目を越えて2周目へ戻ること、ファンファーレが最後まで鳴って止まること、音量の保存、ミュート、裏に回したときの停止、閉じると元のBGMに戻ること、ターンが進まないこと。
- **負荷**：この検証環境（ソフトウェア処理のブラウザ）で、実際の速さの約6〜11倍で描けました。リアルタイムの負荷は1コアの1〜2割ほどの見込みです。

## 限界（録音した音源に替えたほうがよい所）
- **金管の質感**：トランペットの輝き、ホルンの丸い息づかい、合奏の音程の揺らぎは近似です。ファンファーレとヤナイのテーマの「壮大さ」は、録音した金管には届きません。
- **弦**：弓の擦れ、ビブラートの自然さ、ホールの響きは出ていません。ダンジョンの低弦の深さも、録音のほうがはるかに良くなります。
- **笛とクラリネット**：音色が単純で、息のニュアンスや強弱の表情は少ないです。
- **低音**：太鼓と低音（約50〜150Hz）は、スマホのスピーカーではほとんど聞こえません。
- **聴感**：私は耳で聴いていません。上の数値と動作のテストだけで確認しています。
