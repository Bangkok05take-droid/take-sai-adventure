# 33階・真大魔王バーンの覚醒ムービーと白い異空間（2026年10月）

受け取った動画（9667.mp4）を正式採用版として組み込みました。
白い異空間で、玉座に座る老バーンとミストバーンが融合し、真大魔王バーンが目覚める登場ムービーです。

## 動画
- 置き場所：`assets/movies/truevearn-awaken.mp4`
  - 受け取った動画をそのまま置いています。720×1280・10秒・H.264（24fps）＋AAC ステレオで、変換はしていません。
  - 名前テロップは入っていません。新しく足してもいません。
- 最初の1コマ：`assets/movies/truevearn-awaken-poster.jpg`
- 設定の名前：
  - `js/assets.js` の `movies.trueVearnAwaken`
  - `js/data.js` の `D.BOSS_INTROS.truevearn`
- 再生は、ほかのボスと同じ共通の仕組みを使います（`playBossIntro` → `movieOverlay`）。
  - 縦の動画を切らず、引き伸ばさずに全体を表示します（`object-fit: contain`）。
  - 音は動画の音を使います。再生中はダンジョンの曲を止め、終わったらボス戦の曲にします。
  - スキップ・読み込み失敗・アプリを裏にしたときの扱いも、ほかのボスと同じです。
- ムービーを見返す機能はゲームにありません。なので、登録はしていません。

## 流れ
1. 32階で階段を降りる（確認で「降りる」を押す）。
2. 32階の画面がそのまま黒へ暗転します（0.5秒）。曲も一緒に下がります。
3. 黒のまま33階を作り、たけをボス部屋の中に置きます。
   - 置く場所は、入口から3マス入った所です。ボスとの間は4マスで、戦いが始まったときボスが画面に入ります。
   - 歩いたり、ボスに近づいたりする必要はありません。
4. 登場ムービーを再生します。黒からそのまま動画が明るくなるので、33階の画面やボス戦は一瞬も見えません。
5. 動画の終わり（最後まで・スキップ・読み込み失敗のどれでも）：
   - 短い暗転のあと、白い異空間で戦いが始まります。
   - 戦いの開始（サイたちの祈り → 真大魔王バーン戦）は、`G.finishBossIntro` で1回だけ行います。

- コード：
  - ゲーム側：`js/game.js` の `G.arriveBossFloor`（階段で33階に着いたときに1回）
  - 画面側：`js/ui.js` の `doDescend`（降りる前の暗転）・`cover`／`uncover`（黒い幕）
- 対象：`D.BOSS_ARRIVAL = { truevearn: true }`
  - 最終章の配置の版4（33階）だけです。
  - 更新前から続く版3の探索（35階）は、今までどおりボス部屋に入ったときにムービーが流れます（新しい動画）。

## 再生の条件（ほかのボスと同じ）
- **再生中**：移動・攻撃・道具・敵の行動・ターンは止まります。
- **見たら記録**：最後まで見るか、スキップするか、読み込みに失敗すると「見た」と記録します。
  - 記録は `story.introSeen.truevearnAwaken` で、セーブに残ります。
  - 再挑戦・次の探索では流しません。33階に着いたら、すぐに戦いが始まります（このときも歩く必要はありません）。
- **以前の仮の会話との関係**：以前の仮の会話（「ムービー準備中」）を見た記録（`introSeen.truevearn`）とは別にしています。
  - なので、以前のセーブでも正式の動画は1回流れます。
- **途中で読み込み直したとき**：「つづきから」で、黒い画面のまま最初から流し直します。戦いの開始は1回だけです。
- **スキップしても**：ボスを倒した扱いにはなりません。
- **以前の仮の会話**：`bodyReturn`（「体が戻り、ミストの影が亀裂へ逃げる」）は削除しました。確定の物語と食い違うためです。

## シナリオ（確定事項のまま）
- 30階：大魔王バーンを倒す → ミストバーンが連れ去るムービー → 時空の亀裂、の流れは変えていません。
- 33階：
  - 亀裂は出しません。
  - 敵は真大魔王バーン1体だけです。ミストバーンや老バーンが別の敵として出ることはありません。
  - 真大魔王バーンを倒すと、今までどおり最終章のクリアです。
- クリア後の30階の亀裂（隠しダンジョンの入口）と、その先の進み方も変えていません。

## 33階の背景：白い異空間（地域 `void`。名前「白き異空間」は仮）
- 真大魔王バーンのボス部屋の景観を、今までの暗い「封印の玉座」から変えました（`D.ENEMIES.truevearn.arena = 'void'`）。
- 描いているのは `js/render.js` の `drawVoidBg` です。
  - 地図・当たり判定・ボスの位置・戦いのルールは変えていません。描き方だけです。
- **床**：
  - 通れるマス（床・通路）だけを、白い大理石の板として描きます。
  - 縁には細い影の線を入れて、どこまで歩けるか分かるようにしています。
- **壁・天井**：描いていません。白い薄霧の中に溶けこませています。霧はゆっくり流れます。
- **玉座**：ボス部屋の奥（上の縁の外、中央）に、空席の水晶の玉座を置いています。半透明の青白い色で、まわりがほのかに光ります。飾りなので、当たり判定はありません。
- **ゲームの描き方に合わせたこと**：
  - 板と玉座は、ほかの地形と同じ細かさのドットで、コードで描いています。
  - 新しい画像は使っていません。ChatGPT 制作の背景の絵が届けば差し替えられます。
- **見やすさの調整**：
  - 白い床の上でも分かるよう、33階だけ予告の赤いマスを濃い赤にし、縁を暗くしています。
  - 見えていない所は、黒ではなく白い霧で淡くしています。
  - 人物・敵・道具・床の印（数字）・HPバーは、今までと同じ描き方です。
- 倒したあとに33階へ来たときは、ボスのいない階として今までどおりの景観です。
