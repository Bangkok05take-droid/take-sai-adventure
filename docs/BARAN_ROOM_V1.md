- **共通の形**（`js/dungeon.js` の `generateBossFloor`）：広間15×15（x9〜23・y1〜15）、通路 x16・y16〜18、前室5×4（x14〜18・y19〜22）。入口は前室の (16,21)。
  - 広間の真ん中の列から入るので、入口からボス（広間の中央）までは以前と同じ7マスです。
  - 以前は左の前室から右へ入る形でした（前室5×5・通路6マス）。
- **変えていないもの**：ボスの階・能力・技・報酬・物語の進行・入室で戦いが始まる仕組み（`G.checkBossRoom`）・ボスが広間から出ない決まり。
- **進行中のセーブ**：階の地図は保存されているので、今いるボスの階は以前の形（左の入口）のままで遊べます（読み込み直しても変えません）。次にその階を作るときから新しい形になります。
- **33階の到着位置**（`G.arriveBossFloor`）：下の入口の階では、入口の列で広間の下の端から3マス上（上向き）。以前の形の階は今までどおり左から3マス。
- **大技の向き**：どのボスの技も、たけの位置から向きを決めるので、入口の向きに合わせた変更はいりません（予告の向きは、たけのいる方向）。

## 通常バラン戦の部屋（第4章30階）
- 背景：`assets/reference/baran-room-v1/baran_room.png`（941×1672）を引き伸ばさずに敷きます → `assets/rooms/baran-room.webp`。作り方は `python3 -I tools/make-baran-room.py`。
- 1マス＝絵の 49.7px（845/17）。広間の床（絵の y500〜1345）がちょうど17行。地図は19×34マス（`D.BARAN_ROOM`）。
- **広間（戦う床）**：15×17（x2〜16・y10〜26）。今までの広間（15×15）より2行広い。
- **前室・通路**：絵の下の中央の通路（柱の内側 x400〜537）を通れる所にしました。x8〜10・y27〜32（3×6）。入口（たけが立つ所）は (9,32)。最初の道具はここに置きます。
- **壁**：玉座の壇・階段・左右の縁と炎の台・柱・下の通路の両脇。
- **左の旧入口**：通れません。絵の左の開口は、**仮のつぎあて**（同じ絵の左の壁 y990〜1060 を写した）で閉じています。ChatGPT の直した絵が届いたら差し替えます（下の依頼1）。
- **玉座**：`assets/rooms/baran-throne.png` を壇の上の中央に描きます（絵の x470・足元 y398・高さ130px＝2.6マス。**仮**）。当たり判定はありません（壇は壁）。
- **ボスの最初の位置**：広間の中央 (9,18)。入口からの距離は8マス（今までの7マスより1マス遠い）。
- 竜人王バラン（隠しダンジョン）には使っていません。

### 広さ・入口の変更で変わること（報告）
- **バランの広間が15×15 → 15×17**：動ける床が30マス増え、縦に2マス長い。バランの突進・剣技の届く長さや、たけが逃げる余地が少し増えます（技の数値・射程は変えていない）。入口からバランまでは8マス（以前7マス）。
- **共通の形**：通路が6マス → 3マス。ボスは広間から出ないので戦いには影響しません。
- **画面の見え方**：スマホの画面は縦に長いので、下から入ると広間の奥が少し見えやすくなります。入った直後、ボス（7〜8マス上）は画面の上の端の外か端にいます（以前の左の入口でも、横7マスで画面の外でした）。

## ChatGPT への依頼（画像と寸法）
1. **バランの部屋：左の開口を閉じた版**
   - `baran_room.png` と同じ 941×1672。左の壁の開口（x0〜110・y840〜940）を、上下と同じ壁（柱と炎の台・洞窟の岩）に。ほかは変えない。
   - 今は同じ絵の壁を写した仮のつぎあてで、継ぎ目が少し見えます。
2. **バランの部屋：下に前室を足した版**（入口で画面の下半分が黒くなるため）
   - 幅941のまま、下に約300px（6行ぶん、1行≒49.7px）を足して 941×約1972 に。上の1672pxは今の絵と同じ（ずらさない）。
   - 下の通路（柱の内側 x400〜537）をそのまま下へのばし、その先に前室（幅 約5マス＝250px、x345〜595 くらい）。まわりは洞窟の岩と青い水晶で、通れそうな脇道は描かない。
   - 届いたら、前室を通れる所に足して、入口を前室の下の方へ移します（地図の高さ34 → 約40）。
3. **ほかのボスの部屋を作るとき**（順番に刷新するときの寸法の目安）
   - 1マス＝50px。広間は15×15マス（床 750×750px）。下の中央に通路（幅1〜3マス）、その下に前室（5×4マス）。上は壇や玉座などの飾り（通れない）。
   - 絵の床の升目をそのままマスにはしないので、升目は自由。ただし通れる床の外側（縁・柱・壁）ははっきり分けて描く。
   - 左右の縁や下の通路の脇に、出入口に見える開口は描かない。
