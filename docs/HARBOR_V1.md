# 港（船着き場）の改修 v1（2026年10月）

素材は `assets/village/` に置きました（pier・boat・quay・supplies・bollard）。見本と manifest は `assets/reference/harbor-v1/`、指示書は `docs/HARBOR_V1_INSTRUCTIONS.md` にあります。

## 大きさ
建物と同じ倍率（2/3）で描きます。桟橋の板の幅は、サイの店の扉の幅とほぼ同じです（人物1人が通れる幅）。スマホ（1ドット＝3ピクセル）では、素材の1ドットがちょうど2ピクセルになります。

## 配置と通行
| もの | 場所 | 通れるか |
|---|---|---|
| 岸壁（quay） | 川の上の岸（21行の下の縁に上面の石、22行の水へ前面の石積み）。左右の余白を除いた 252 ドット分を横に並べる。赤い橋（村の発展「橋」）の所は空ける | 通行は地図のまま（岸の道 20〜21行は通れる、水は通れない） |
| 桟橋（pier） | x10 の列の中央。上端を岸壁の上面に重ねて陸とつなぐ。川（3マス）に合わせ、くり返しの区間（綱の所で切る）を抜いて短くした | **板の上の (10,22)・(10,23) だけ**。欄干（x9・x11）・水・桟橋の先 (10,24) は入れない |
| 小舟（boat） | 桟橋の先の右に横付け（乗る場所が分かる） | 舟の上は歩かない |
| 係留杭（bollard） | 岸の縁 (8,21)・(13,21) | そのマスだけ通れない |
| 荷物（supplies） | 右の岸 (16〜17,21) | そのマスだけ通れない |

- 岸の道の20行は、どの列も通れます（杭・荷物・灯り・ティウは21行、鉢は20行のうち2か所）。
- 岸の灯り（村の発展「灯り」）は、ティウや杭と重ならないよう (2,21)・(6,21)・(15,21)・(18,21) に移しました（以前は (7,21)・(12,21)・(17,21) で、(12,21) がティウと重なっていました）。
- 向こう岸のヤシ (13,25) は舟を隠すので、(5,25) に移しました。
- 以前のコードの桟橋（2列）と舟は、素材の絵があるときは描きません。読み込めないときだけ以前の絵で描きます。水面は今までのコードの水と蓮です。

## 出発の操作
- **出発する場所:** 桟橋の先 (10,23) で、舟（右）を向いて出発します（以前は岸の (11,21) で右向き）。
- **タップで出発:** 次のどれをタップしても、桟橋の先まで歩いて「遺跡へ出発」の画面が開きます（乗船費や道具の条件は増やしていません）。
  - 案内人ティウ（入口わきの陸 (12,21)、以前と同じ）
  - 桟橋・舟（タップの範囲は桟橋と舟の所だけで、岸の道は含みません）
  - 下の「出発」ボタン
- **キー操作:** 桟橋の先で右を押すと開きます。
- **舟の揺れ:** 舟だけ、描く位置を約1ドット・4秒周期で上下させます。操作の範囲と地図の座標は動きません。「動きを減らす」設定では止まり、村の画面を離れると描かれません（描画のループの中だけで動かし、タイマーは使いません）。

## 変えていないもの
セーブ・所持品・村の発展・章・ボスの階・音楽、ティウの位置と会話。

## 改修前後の比較
`docs/harbor-v1/` に、同じ村の状態・同じたけの位置・同じ画面の大きさで撮った「左：改修前／右：改修後」を置いています。
- たけの位置は `harbor` が (10,21)、`harborL` が (4,21) です。
- 画面の幅は 390・360・430 です。
- 撮り直しは `node tools/village-shots.js 出力フォルダ` でできます。
