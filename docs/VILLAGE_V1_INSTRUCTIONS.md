# 村の部分改修・子供と猫の移植 v1
このパックを使って「サイの店～ヤナイ像の広場」を実際に遊べる完成区画にしてください。ゲーム全体を一枚の見本画像に置き換えないでください。

## 素材
個別透過PNG24枚：子供3種×正面/右/背面、猫3種×座る/右向き/眠る、店・像・木・花壇・屋台・ベンチ6点。
manifest.jsonは画像寸法と足元アンカー。preview.pngは各素材を個別に拡大した一覧で、相対的な大きさの比較には使わない。village-reference.pngは雰囲気と配置の参考のみ。
画像生成した素材を透過抽出・最近傍縮小したもの。手打ちピクセル素材ではない。透過と切り出しを検査し一覧を目視確認済み。ゲーム内での描画・通行・実機動作は未検証。
地面タイル・水面タイル・歩行連番は同梱しない。現行素材を使用し、今回できたことと今後の制作を区別する。

## 最初に既存実装確認
村のタイルサイズ、座標系、人物描画寸法、画像登録方法、Yソート、施設の解放フラグ、クリック範囲を読み、既存の動作を保って導入する。manifestは提案規格であり現行コードに自動的に適合する保証はない。
子供は64x64セル、足元(32,60)、絵の高さ約34px。大人の実際の描画高さの70～80%を目安に統一。透明余白を含む64px全体を1タイルへ機械的に縮めない。猫は32x32足元(16,28)、絵の高さ約20px以下。猫を大人と同じ大きさにしない。
人物の左向きは右向き画像の反転可。猫には背面がないため今回は左右の短い散歩と座る/眠るに限定。子供の3方向は歩行3コマではない。足を交互に動かす歩行アニメとして順番再生しない。今回は静止配置を基本とし、猫の短い移動は位置補間の簡易表現として報告する。

## 区画の仕上げ
サイの店画像を既存店舗に組み込み、入口とショップ操作を一致させる。像は既存解放条件を守り未完成セーブに勝手に追加しない。屋台・花壇も発展状態を反映。既存の像や屋台と二重に描かない。
既存の石畳と芝生を使い、道を残して植栽を端に寄せる。入口前に最低2マス、主要動線に最低2マス相当の余裕を確保。実際の地形に合わせて調整。
建物は足元を基準に配置し、画像の四角全体を通行不可にしない。木は幹付近だけを障害物とする。見た目の屋根・樹冠と地面の当たり判定を区別する。現行の前後描画方式に沿って、人物が不自然に屋根上へ出ないようにする。
像・建物は足元または地面用の描画順を個別設定し、Yソート任せで破綻させない。共通光源は左上、必要なら足元に控えめな影をコードで描く。

## 子供と猫
child_play：広場の脇。会話案「きょうも冒険に行くの？」
child_book：木陰のベンチ近く。立ち絵なので座らせたように無理に重ねない。会話案「遺跡の本を読んでいるんだ。」
child_cat：サイの店近く。会話案「この子、サイちゃんが大好きなんだよ。」
cat_ginger：サイの店先。調べると「にゃー。すりすりと寄ってきた。」
cat_calico：店の横で眠る。調べると「すうすう……気持ちよさそうに眠っている。」
cat_black：花壇沿いに左右へ短く歩く。調べると「にゃっ。しっぽをぴんと立てた。」
これらは戦闘対象にせず村限定。猫は通行を塞がない。店・出発・倉庫等の操作を優先し、NPCのクリック範囲を過大にしない。会話で資金・満腹度・ダンジョンのターンを変更しない。追加会話のために音源制作は不要。
猫の位置等は永続化必須ではない。村再生成・出入りのたびに数が増えないよう安定したIDで管理。屋内、川、建物内へ移動しない。画面を閉じたらタイマーを解除、非表示時は停止。

## 検証
まず対象区画を完成させる。店へ移動・購入、像/施設の解放前後、既存セーブ再開、村を出入りしてもNPC重複なし、通路が塞がらないこと。360/390/430px幅でキャラの相対サイズ・猫の見やすさ・UI重なりを確認。改修前後を同位置で撮影して報告。
主人公やサイの画像、ボス配置、アイテム性能、音楽、所持品、章進行を不用意に変更しない。
通常のブランチclaude/take-sai-adventure-game-loh1feにコミットして通常プッシュ。実装済み・未実装・未検証を区別して報告。
