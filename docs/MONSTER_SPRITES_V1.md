# 通常モンスター15種の絵と名前（2026年10月、ZIP monster_sprites_v1）

ChatGPT 制作の素材を、そのまま組み込みました。描き直しや加工はしていません。左右の反転は、ゲームの中で描くときだけ行っています。

## ZIPについて（大事）
- 受け取った ZIP は、途中で切れていました。ファイルの最後の目次が無く、`baby_satan/source.png` の途中で終わっています。
- 中身の各ファイルの壊れ検査（CRC）を確かめて、無事なものだけ取り出しました。85ファイルです。
- **ドラキー（`dracky`）の画像は、1枚も入っていませんでした。** manifest と size_preview には載っています。
  - ドラキーは、今までのコードの絵（旧ヤミコウモリの絵）のままにしています。名前だけ「ドラキー」です。
- ベビーサタンは、`00.png` と `source.png` がありません。ただし `sheet.png`（4コマ）が無事なので、これを使っています。
- **ドラキーの再送（ZIP dracky_fix_v1、47,812バイト）を組み込みました。**
  - ZIP の目次と CRC は正常で、SHA256SUMS もすべて一致しました。
  - `sheet.png`（384×96）は、個別の `00〜03.png` と同じ内容です。
  - 透過あり、足元は y=84、待機の本体は40px です。
  - 攻撃発動のコマは右向きです。
  - 元の素材：`assets/reference/monster-sprites-v1/dracky/`
  - ゲーム内の表示：`dracky_ingame_390.png`（待機A・B、攻撃準備・発動。たけの左から＝反転なし、右から＝反転）

## 大きさ
- たけの本体の高さは47ドットです（`take_front.png` の不透明な範囲 y=15〜61）。
- 大型の待機の本体（64px）を47ドットにする倍率（47/64＝約0.73）を、全種・全コマで同じにかけています。
  - **大型3体**（うごくせきぞう・ゴーレム・あくまのきし）：本体47ドット。たけと同じ高さです。
  - **小型12体**：本体29.4ドット。たけの0.625倍です。
- 透明な余白ではなく、本体の高さでそろえています。武器を振り上げても倍率は同じなので、体の大きさは変わりません。
- **足元**：コマの足元（x=48・y=84）を、たけと同じ足元の高さ（マスの下端の1ドット上）にそろえました。
- **描き方**：最近傍で描いています（ドット絵のまま）。
- **当たり判定**：位置・当たり判定・通れるかどうかは、今までどおり1マスです。
- **見え方**：
  - 横に大きい絵は、となりのマスに少しかかります。ぐんたいガニは約1.8マス、ゴーレムは約1.6マスです。

## 動作のコマ（見た目だけ。判定はゲーム側で1回だけ）

| 場面 | コマ | 対象 |
|---|---|---|
| 待機 | 待機A・待機B を0.42秒ごとに切り替え（以前の1ドットの上下はやめた） | 全14種 |
| 移動 | 待機のコマのまま、今の移動（1マス0.11秒）で滑る | 全14種 |
| 近接攻撃 | 準備0.14秒 → 発動0.16秒。踏み込みと、当たり・ミスの数字は発動に合わせて0.14秒遅らせる | スライム・ドラキー・ぐんたいガニ・リリパット・きりかぶおばけ・まほうつかい・バブルスライム・ゴーレム・さまようよろい・あくまのきし・ベビーサタン・うごくせきぞう |
| 射撃 | 準備0.14秒 → 発動で矢が飛ぶ（今の矢の演出）。数字は届いたとき（0.29秒） | リリパット（矢）・まほうつかい（火の玉）・ベビーサタン（火の玉） |
| 予告の大技 | 予告の間は準備のコマ（赤い点滅・「！」はそのまま）→ 発動の0.36秒は発動のコマ | うごくせきぞう・ゴーレム・さまようよろい・あくまのきし |
| 盗み | 盗む動作（準備 → 発動）を、逃げる前の場所に残して見せる | おどるほうせき |

- **向き**：技のコマは、たけのいる横の向きに合わせて左右を反転します。
  - 絵が向いている向き：スライム・うごくせきぞう・ゴーレム・さまようよろい・あくまのきしは左、そのほか（ドラキーを含む）は右です。
- **撃破**：今までどおり、つぶれながら白く消えます。待機のコマで描きます。足元もそろえています。
- **使っていないコマ**：
  - ホイミスライムの回復のコマ：今は回復の行動が無いため。
  - メタルスライムの逃走のコマ：今は逃げる行動が無いため。
  - おどるほうせき・ホイミスライム・メタルスライムが体当たりするとき：技のコマは盗み・回復・逃走なので使わず、待機のコマで踏み込みます。
- **二重表示**：リリパットの矢、ベビーサタンの火の玉は、発動のコマの絵の中にもあります。
  - そのうえで今の矢の演出も飛ぶので、発動の0.16秒だけ、絵の矢と飛ぶ矢が近くに見えます。
  - 対策は「判断が必要なこと」に書きました。
