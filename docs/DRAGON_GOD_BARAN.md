# 竜魔神バラン（隠しダンジョン35階）の仕様（2026年10月28日・実装待ち）

ダンジョン制作（封印の最深部・大魔王の城）が終わってから実装する。素材：`assets/reference/baran-images-v2/`（キャラクター・技のポーズ・エフェクト・登場動画）。

## 名前
- 正式名称「竜魔神バラン」（意図的に「竜魔神」）。通常形態は「竜騎士バラン」。

## 確定
- 今の技（なぎ払い・突進・十字のドルオーラ）はすべて外し、下の3つの技に入れ替える。
- HPが半分を切ったらドラゴニックオーラが強まる（強化は残す）。ドルオーラは強くなるが、一直線のまま（十字にしない）。
- ギガブレイクで5マス先にたけがいるとき：たけを1マス押し出して5マス目に止まる（押し出せないときは手前で止まる）。
- 登場動画は35階に着くたびに毎回流す。

## 技（指示書どおり）
- ドルオーラ：直線3マス、8方向。溜め1ターン（向きは溜め始めに固定・予告）→ 次のターンに発射 → 1ターン休み。バランは動かない。
- ギガブレイク：溜め1ターン（剣を頭上・雷・向きを固定・予告）→ 次のターンに直線5マスを駆け抜ける（演出約0.12秒・斬り抜けのポーズ）。途中のたけにも当たる（1回だけ）。壁の手前で止まる。休みなし。
- 竜闘気（ドウラ）：1ターン使う → 続く3ターンは1ターンに2回行動・防御1.5倍・通常攻撃と移動だけ → 終わりにオーラが弾けて消え、1ターン休み。
- 演出の時間とターンの処理は分ける。

## 数値（案・未確定）
- HP 1500・攻撃 52・防御 23（今のまま）。通常攻撃1.0倍。
- ドルオーラ2.4倍・次まで5ターン。ギガブレイク2.0倍・次まで6ターン。竜闘気はHP70%で初回、終わってから12ターンで再使用。
- HP半分のドラゴニックオーラ：攻撃力1.15倍（今の値）。
