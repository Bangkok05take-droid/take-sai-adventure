# 竜魔神バラン（隠しダンジョン35階）の仕様（2026年10月28日・実装済み）

素材：`assets/reference/baran-images-v2/`（キャラクター・技のポーズ・エフェクト・登場動画）。ダンジョン制作より先に実装した（10月28日の指示）。

## 名前
- 正式名称「竜魔神バラン」（意図的に「竜魔神」）。通常形態は「竜騎士バラン」。

## 確定
- 今の技（なぎ払い・突進・十字のドルオーラ）はすべて外し、下の3つの技に入れ替える。
- HPが半分を切ったらドラゴニックオーラが強まる（強化は残す）。ドルオーラは強くなるが、一直線のまま（十字にしない）。
- ギガブレイクで5マス先にたけがいるとき：たけを1マス押し出して5マス目に止まる（押し出せないときは手前で止まる）。
- 登場動画は35階に着くたびに毎回流す。

## 技（指示書どおり）
- ドルオーラ：直線3マス、8方向。溜め1ターン（向きは溜め始めに固定・予告）→ 次のターンに発射 → 1ターン休み。バランは動かない。
- ギガブレイク：溜め1ターン（剣を頭上・雷・向きを固定・予告）→ 次のターンに直線5マスを駆け抜ける（演出約0.12秒・斬り抜けのポーズ）。途中のたけにも当たる（1回だけ）。壁の手前で止まる。休みなし。
- ギガブレイク（なぎ払い。10月28日に復活・技名は同じ）：隣にいるとき、まわり1マスを予告1ターン → 振り抜く。休みなし。当たるとたけを1マス後ろ（バランから離れる向き）へ押す（押せなければその場）。溜めの見た目は突進と同じ。振り抜くポーズは、専用の絵が届くまで突進・斬撃の絵。
- 竜闘気（ドウラ）：1ターン使う → 続く3ターンは1ターンに2回行動・防御1.5倍・通常攻撃と移動だけ → 終わりにオーラが弾けて消え、1ターン休み。
- 演出の時間とターンの処理は分ける。

## 数値（案・未確定）
- HP 1500・攻撃 66・防御 50（10月28日「弱い」のご指摘で 攻撃52→66・防御23→50。防御を特に上げた）。通常攻撃1.0倍。
- なぎ払いのギガブレイク：2.0倍・次まで4行動（突進とは別に数える）。
- ドルオーラ2.4倍・次まで5ターン。ギガブレイク2.0倍・次まで6ターン。竜闘気はHP70%で初回、終わってから12ターンで再使用。
- HP半分のドラゴニックオーラ：攻撃力1.15倍（確定。すべての攻撃に効く）。
- 技の順：竜闘気（条件を満たしたとき）→ ギガブレイクのなぎ払い（隣）→ ギガブレイクの突進（一直線2〜5マス）→ ドルオーラ（一直線2〜3マス）→ 通常攻撃・移動。

## 実装（どこに何があるか）
- 数値：`js/data.js` の `D.DRAGON_KING`。動き：`js/bossai.js` の `AI.dragonbaran`・`RES.gigabreak`（突進）・`RES.gigasweep`（なぎ払い）。
- 絵：`tools/make-dragon-god-baran.py` が原画から作る（描き直しはしない。縮小と配置だけ）。
  - `assets/bosses/dragonbaran.png`（待機）・`-doruora`（ドルオーラの構え）・`-sword`（剣を頭上に）・`-dash`（突進・斬撃。左へは反転）。3倍の細かさで持ち、画面ではボスの枠（96×96、突進は128×128）として描く。占有・当たり判定は1マスのまま。
  - 本体の高さは72ドット（竜騎士バラン65・真大魔王バーン66より少し大きい）。構え・突進の絵は頭の大きさがそろう倍率。
  - 技の演出：`assets/fx/dragonbaran/`（3枚のシートを4区画ずつ切り出し、余白を切った絵）。大きさはマスの単位で `js/fx.js` が決める。
- 演出の秒数（`TS.FX.DB`）：ドルオーラは溜め0.14秒＋飛ぶ（1マス0.09秒・最短0.24秒）＋爆発0.3秒。ギガブレイクは突進0.12秒＋斬撃の残り0.38秒。ターンの数とは無関係。
- 登場動画：`assets/movies/dragon-god-baran-intro.mp4`（元の動画をそのまま。情報の位置だけ前へ）。`D.ARRIVAL_MOVIES` で35階に階段で着くたびに流す（スキップ可）。戦いはいつもどおりボス部屋に入ってから。
- 画面の確認：`node tools/dragon-god-baran-check.js`（画像は `tests/screenshots/dragon-god-baran/`）。
