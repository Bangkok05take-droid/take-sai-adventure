# 村の飾り v1：街灯・白いゾウの像・噴水・赤い橋（2026年10月）

素材は1枚の見本です（`assets/reference/village-decor-v1.png`、透過、4つの部品）。このときの依頼には CLAUDE_INSTRUCTIONS.md が付いていなかったので、依頼の文と、これまでの素材の決まりに合わせて組み込みました。今回は飾り4点だけです（ストーリー動画は別の作業）。

## 素材の作り方（`python3 tools/extract-decor.py`）
- 見本から4つの部品を切り出し、ふちの薄い半透明（透明度200未満）は消しました。面積の中央値で縮小して、村の大きさそのままの絵（`assets/village/decor/`）にしています。描き直しはしていません。
- 大きさは、新しい店・植木（鉢・花壇）と並べて揃えました。
  - 街灯：0.11倍で 15×59。人物より少し高い。
  - 白いゾウの像：0.11倍で 53×56。マスターヤナイの像より小さく、ベンチと同じくらい。
  - 噴水：0.16倍で 78×77。2マス幅の台座。
  - 赤い橋：0.33倍で 72×131。欄干の内側の床が人1人分の幅。縦に長い見本なので、中ほどの同じ形のくり返し（床板と手すり）を抜いて、岸壁から向こう岸の草地までの長さにしました。

## 配置（場所・解放条件・購入状態は今までのまま）
| もの | 場所 | 解放（今までと同じ） | 通れるか |
|---|---|---|---|
| 街灯 | 今までの灯籠の場所。(6,8)・(13,8)、第2章〜か「灯籠の並木」で (5,16)・(14,16)、「灯籠の並木」で岸壁の4本 | 同じ | 足元の1マスは通れない（今までと同じ） |

| 赤い橋 | 水路の x3、22〜24行（縦向き） | 「水路の赤い橋」（地下10階） | 橋の中央 x3 だけ通れる |

- **赤い橋**：床板の上端を岸壁の上面に重ね（親柱が岸壁の上に立つ）、下端は向こう岸（25行）の草地にかけました。岸壁は切らずに続けています。
  - 以前の橋は2列（x3・x4）でしたが、「人物が橋の中央を歩く」ため、素材の橋では中央の x3 だけを通れるようにしました。欄干の外（x2・x4）は水なので通れません。
  - 前後関係：床板は人物の奥に描きます。左右の欄干は8ドットずつ横に切って重ね直しているので、人物の足元より下の欄干は人物の手前に描かれます（盾やマントが欄干の後ろに隠れる）。
- **街灯**：灯りの光（今までの光の輪）は灯りの頭の位置に合わせました。
- **噴水**：しぶき（今までの水しぶきの粒）は吹き出し口の位置から出します。石の部分と像は動かしません。
- 絵が読み込めないときは、以前のコードの絵（灯籠・白い四角の象・噴水・赤い板の橋）で描きます。
