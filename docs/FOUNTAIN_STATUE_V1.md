# 噴水の水流と「マスターヤナイの像」（2026年10月）

素材はZIP「take-sai-fountain-endgame-v1」です。元の素材・描画の見本（fountain-overlay.js）・指示書・企画メモ（PLAN.md）は、`assets/reference/fountain-endgame-v1/` にそのまま置いています。

## 噴水の水流（村の発展「噴水」を建てたとき）
- **絵**
  - `assets/village/decor/fountain_spray.png` を使います。ChatGPT制作の透過の水流（1328×1173）を、縦横比のまま幅256に縮めただけです（描き直しなし）。
  - 噴水の本体（今までの石の噴水の絵）はそのままで、揺らしません。
  - 本体の絵の中にある、下の段へ落ちる水もそのままです。
  - 今までの上の小さな水しぶき（粒）は、水流に置き換えました。水流の絵が読み込めないときは、今までどおり粒を出します。
- **描き方**
  - `js/render.js` の `drawFountainFx` で描きます。見本の `drawFountainSpray`・`drawFountainRipples` の計算と数値を、そのまま移しました。
  - 水流
    - 下端中央を、噴水の頂の飾りの先（噴水の絵の中の (39,2)）に合わせます。
    - 幅は、外側の水盤の幅（噴水の絵の幅78）の0.46倍です。不透明度は0.82です。
    - 縦にだけ、±2.5%でゆっくり伸び縮みします。
  - 波紋
    - 外側の水盤の楕円（中心 (39,41)、横29・縦13）の中に、3つの輪が広がります。不透明度は最大0.24です。
    - さらに、噴水の絵の「外側の水面」の点だけに残します（水面の1点から色でたどって作った形を使います）。
    - そのため、段の石・前の石縁・上の段の水には出ません（前の石縁が手前に見えます）。
  - 座標と時間
    - 位置は世界の座標で渡し、カメラの位置と倍率は1回だけかけます。
    - 時間は今までの描画ループの時刻を使い、新しいタイマーは作っていません。
  - 「動きを減らす」設定では、伸び縮みと波紋を止めます（水流の絵は出します）。
  - 位置と大きさの数値は、`js/assets.js` の `decor.fountainFx` にまとめています。

## マスターヤナイの像（旧「黄金の門」）
- **発展の項目**
  - 村の発展の飾り「黄金の門」を「マスターヤナイの像」に変えました。
  - 値段（1500）と解放条件（お宝を9種類寄贈）は、そのまま引き継いでいます。
  - 内部IDは `gate` から `yanai_statue` に変えました。
- **建てる前**
  - 広場に像・台座・名札は出ません。話しかけることもできません。
  - 像があったマス (9〜10,11〜12) は、広場の床として歩けます。
- **建てたあと**
  - 今までの像の絵を、今までの場所 (9〜10,11〜12) に置きます。名札・当たり・話しかけ（師匠の言葉）も、今までどおりです。
- **以前の金の飾り**
  - 「黄金の門」の金の飾り（遺跡の門の頂の飾り・敷居の帯）は、描かないようにしました。
- **既存のセーブ（版6 → 版7、`js/save.js`）**
  - 黄金の門を買っていれば、像を建てた扱いにします。追加の支払いはありません。
  - 買っていなければ、像はありません。以前は最初から広場に像がありましたが、それを購入済みとは判定しません。
  - 資金・ほかの施設・進行は、そのままです。
