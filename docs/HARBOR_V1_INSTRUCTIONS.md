# 港の改修用素材 v1
サイの店と更新済み施設に合わせて、現在の船着き場を整える。今回は港のみ。街全体の床、アユタヤ遺跡周辺は次工程。

## 同梱
pier.png：96x224、縦方向の桟橋。
boat.png：256x96、横向きの屋根付き小舟。
quay.png：256x64、水平な石造りの岸壁。
supplies.png：96x64、樽・木箱・ロープの一体小物。
bollard.png：32x64、独立した係留杭。
各-source.pngは高解像度原画。manifest.jsonには寸法・不透明絵の矩形・足元アンカーを記録。preview.pngは一覧で、画面内の相対サイズを示す配置図ではない。
内蔵画像生成で制作し、透過抽出・最近傍縮小で書き出した。手打ちドット素材ではない。透過と切り出し、縮小一覧は確認済み。ゲーム接続や実機確認は未実施。

## 実装
既存の港座標、出発の当たり判定、案内人ティウ、カメラ、川と陸の地形、クリック操作を確認してから差し替える。
既存の出発動線を維持。桟橋の上端を陸に接続し、中央の板部分だけ歩ける。欄干・水・桟橋の外側を歩けるようにしない。画像の透明な余白はmanifestのcontent_rectで確認。
舟は桟橋の先端に横付けし、見た目で乗船場所が分かるようにする。元の出発ボタンと船着き場からの操作を維持し、新たに乗船費やアイテム条件を追加しない。船体の上を自由に歩ける必要はない。
ティウを入口近くの陸上へ配置し、桟橋やボタンの操作を妨げない。係留杭と荷物は岸の脇へ寄せる。元の船・桟橋・岸壁・小物の重複描画を防ぐ。
画像サイズは書き出し寸法でありCSS表示寸法ではない。人物・サイの店・タイル幅と比較して倍率を決める。船は人物が乗れる大きさを確保するが、画面を塞がない。

## 岸壁
quay.pngは水平の外観部品で、完成した全方向オートタイルではない。左右2px等の透明余白を含むため画像幅そのままの反復は隙間の原因になる。content_rectを元に切り出して既存岸辺に沿って配置し、継ぎ目を目視確認。角や桟橋接続部は既存地形描画で補完。歩行判定を岸壁画像から推測して変更しない。
上面の石と前面の暗い石積みで高低差を表現。水際に細い影や控えめな明るい波線を加えてよい。陸との段差、桟橋入口の連続性を確認。

## 水と動き
水面タイル・水面連番は未同梱。既存水面を使用。濃い青緑の水に控えめな波紋を描く程度に留め、今回新たな大規模水面システムは作らない。
舟のみゆっくり上下する簡易演出（基準描画で約1px程度、周期3～5秒）を許容。描画オフセットのみ変更し、出発判定とマップ座標は動かさない。桟橋・岸壁・杭は固定。prefers-reduced-motionで停止、村を離れたら演出処理を終了。追加タイマーの重複を避け既存描画ループを使う。

## 保護・検証
セーブ、所持品、村の発展、章、ボス階層、音楽を維持。港の開放条件があれば引き継ぐ。
360/390/430px幅で港へ移動、出発、帰還を確認。欄干や川への侵入不可、入口を荷物やNPCが塞がない、帰還地点が有効、連打で二重出発しないこと。カメラを動かしても絵と操作位置がずれないこと。改修前後を同じ位置で撮影して報告。
