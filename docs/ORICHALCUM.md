# オリハルコン・勇者の剣・勇者の盾・無限強化（2026年10月21日）

## 決まったこと（ご指示どおり）
| 項目 | 内容 |
|---|---|
| オリハルコン | 新しい鍛冶の素材（`D.ITEMS.orichalcum`）。持ち帰ると素材箱に入る |
| 出る所 | **30階から（30階を含む）**。床に置く道具・敵を倒したときの落とし物。33階の真大魔王バーンの決戦場は最初に置く道具なしのまま |
| ティウ | 30階の救援（倉庫の交換・オオカミの配送）の帰り際に「町まで持って帰る」と話す。その場では渡さない。町でティウに話しかけると**1個**、1回だけ。**倒れても・途中で帰っても**受け取れる（救援を終えた時点で村の記録 `story.oriTiw` に残す） |

| 無限強化 | 勇者の剣を打つと解放（`story.heroForge`）。**すべての武器・盾**が +8 より先へ（アクセサリーは対象外）。今の強化値はそのまま |

| 勇者の盾 | マスターヤナイの像を建てたあと、ワーン（食堂）に話しかけると渡してくれる。1回だけ。像を先に建てていても起きる |
| ワーン | もともとマスターヤナイの恋人。会話はその設定で作った（`D.STORY.orichalcum.waanShield`） |
| 勇者の剣・盾 | お宝から**装備・強化できる品**へ（IDは以前のお宝の `hero_sword_relic`・`hero_shield_relic` のまま）。売れない |

## 任せていただいた数値（変えたいときは `js/data.js`）
- 勇者の剣：**攻撃力 30**（これまでいちばん強い覇者の剣は 27）
- 勇者の盾：**防御力 24**（これまでいちばん強いドラゴニックオーラの盾は 22、覇者の盾は 19）
- どちらもゲームの中でいちばん高い基礎の数値。

## 聞き取りから決めた値（違っていたら直します）
- オリハルコンの出る確率：**床・敵とも 5%**（`D.ORICHALCUM.floor`・`drop`）。
  - 床：30階からの階で、置く道具1つごとに 5% でオリハルコンになる（モンスターハウスの道具も同じ）。
  - 敵：30階からの階で、倒した敵が 5% でオリハルコンを落とす（そのときはふつうの落とし物の代わり。呼ばれた敵は落とさない）。

## 流れと画面
1. 30階：大魔王バーンを倒す → ティウの救援 → オオカミの配送の画面で「進む」→ ティウ「そうそう、さっきオリハルコンを拾ったんだ。…そのとき渡すよ！」
2. 町：ティウに話しかける → 「おかえり！ 約束のオリハルコンだ。…」→ 素材箱にオリハルコン1個。2回目からはいつもの冒険案内。
3. 鍛冶屋（コイ）：オリハルコンがあれば、会話 → 勇者の剣（バッグへ。いっぱいなら倉庫）→ そのまま鍛冶屋の画面（強化の上限「なし」）。2回目からは鍛冶屋だけ。
   - 鍛冶屋の設備が +8 まで（大きな炉の次の段階）届いていないと、+9 へは進めない（今の設備の上限のまま）。
   - 解放前に +8 の品を強化しようとすると「ここから先は、伝説の金属が要りそうだ……。」
4. 食堂（ワーン）：像があれば、会話 → 勇者の盾 → そのまま食堂の画面。2回目からは食堂だけ。

## 変えていないもの
本編の階・亀裂の道・ボス戦の流れ。33階の決戦場（最初に置く道具なし）。
