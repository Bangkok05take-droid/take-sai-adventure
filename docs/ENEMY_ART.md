# 通常の敵のドット絵：必要な素材の一覧

ボス7体とたけ・サイたちは見本のドット絵になりましたが、**通常の敵15種類は、まだコードで描いた暫定の絵（32×32）**です。
この環境には画像を作る機能がなく、ボスと同じ品質の絵を作れないため、暫定の絵を完成品として置き換えることはしていません。
下の条件で見本（一覧画像）をいただければ、`tools/extract-enemies.py` で切り出して、すぐゲームに組み込めます。

今の暫定の絵の一覧：[enemy_current.png](enemy_current.png)（コードで描いた32×32を4倍で表示。右下は大きさの比較用のたけ）
能力・出現階・2コマの違いの詳しい一覧：[catalog/ENEMY_LIST.md](catalog/ENEMY_LIST.md)

## 今ある動き（素材がなくても入っているもの）
実際にマスを移動している間・攻撃しているときだけ動き、待機中に勝手にターンは進みません。
- ガマ蛙：移動のたびに短く跳ぶ。石ガメ：のそのそと左右にゆれる足運び。吹き矢ザル・金ぴかザル：軽い足運び。
- 吹き矢ザル・光の精・魔界の小鬼：撃つ前に一瞬のけぞって狙い、そのあと矢が飛ぶ。
- すべての敵：攻撃のときの踏み込み、被弾の点滅と揺れ、撃破で短く消える。

## 共通の条件
- **画風**：採用済みのボス（`assets/reference/bosses.png`）・たけたちと同じ、小さい頭身（2〜3頭身）のドット絵。黒い輪郭線、光は左上から、同じくらいのドットの細かさ。
- **大きさ**：たけ（背丈48ドット）より控えめか同じくらい。目安は背丈 **28〜46ドット**（下の表）。ボス（65〜73ドット）より必ず小さく。
- **見本の描き方**：1枚の画像に敵を並べ、**比較用のたけを1体いっしょに描く**（大きさの比を合わせるため。ボスの見本と同じ形）。
  背景は単色・グラデーションでよい（取り除きます）。敵どうし・文字・枠が重ならないよう、まわりに余白を。
- **向き**：正面（少しだけ右か左を向いた正面でもよい）。横向き・背面は無くても動きます（あればダンジョンで使えるよう追加します）。
- **動作コマ**：待機2コマ（呼吸や揺れの差だけでよい）。攻撃ポーズ1コマがあれば攻撃の踏み込みに使います（無ければ今の踏み込みの動きで代用）。
- **ゲームでの形式**（切り出し後）：1コマ 64×64、足の裏 y=60、足元の中央 x=32。2コマは横に並べて 128×64。当たり判定・占有マスは1マスのまま変わりません。
- **組み込み**：`js/assets.js` の `TS.ASSETS.enemies` に `sprite名: 'assets/enemies/○○.png'` を書くと、その敵だけ画像に替わります。
