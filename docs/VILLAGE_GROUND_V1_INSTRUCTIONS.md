# 街の床のブラッシュアップ 第1版

現在のブランチの最新コードと、この素材を使って街の床を改善してください。
既存のサイの店・更新した施設・港・人物・子供・猫に合う床に整える作業です。

## 素材と配置
- sandstone.png：淡い砂岩の石畳。中央広場と主要な歩行路。
- brick.png：赤茶のレンガ。港沿いの遊歩道と既存のレンガ部分。
- grass.png：草地。既存の庭・植え込みの地面。通路は草で埋めない。
- earth.png：土。既存の土部分、木の根元などに控えめに使う。
- 各画像は128×128、32pxの論理タイル4×4に相当する連続した模様。128pxを1マスに縮小しない。
- 各-source.pngは生成元の切り出し。通常描画は128px版を使用。
- repeat-preview.pngはそれぞれを3×3回並べた確認画像。

## 実装
1. 現在の村の地形データ、床の描画関数、カメラ座標、拡大率を確認する。
2. 既存の地形種に対応づける。施設位置、入口、通行判定、出発、会話や操作を変えない。
3. ground-draw.mjsは描画例。現在の名前空間・読み込み方式に合わせて取り込む。例をそのまま新しいゲーム基盤として置き換えない。
4. 模様の位相はワールド座標で固定する。カメラ移動や再描画のたびに模様を変えない。画像の一部分を各マスでランダムに選ぶと石組みが切れるので禁止。
5. 既存のタイルサイズが32以外なら、素材の切り出し32pxとゲーム内の描画サイズを分離する。既存のdevicePixelRatio対応を維持。画像の読み込みは初期化時に行い、失敗時は既存描画へ戻す。
6. 床→地面の小物・接地影→建物や人物の既存の前後関係で描く。床画像が人物や猫に重ならないようにする。
7. 地形境界は既存の境界・縁石を活用し、必要箇所を仕上げる。草と土は平面の境界、縁石は小さな段差として描き分ける。木や施設の入口を隠さない。通行可否は見た目の縁から推測して変更しない。
8. 全面に汚れや装飾を追加しない。床の明暗が人物より強ければ描画側で控えめに調整し、変更内容を報告する。

## 素材の範囲・制約
これは4種類の基本テクスチャで、四隅・内角・全接続パターンを持つ完成済みオートタイルセットではありません。
生成画像を切り出して最近傍で縮小したもので、手作業でピクセルを整列した素材ではありません。
繰り返しプレビューは確認済みですが、完全な無継ぎ目を保証するものではありません。石畳・レンガのパターン境界で目地がずれる箇所は実際の描画倍率で確認し、必要なら元画像の切り出し範囲や接続部分を調整してください。過度なぼかしで隠さないでください。
実ゲームへの取り込み・実機スマホ表示は、このパック作成側では未確認です。

## 確認
- 広場、サイの店、鍛冶屋、食堂、倉庫、展示室、港まで移動し、床の継ぎ目・ちらつき・画像の欠け・カメラ移動時の模様のずれを確認。
- 建物入口、船着き場、施設メニューが従来どおり使え、NPCと猫が床に隠れないことを確認。
- 360・390・430px幅で表示と操作を確認。同じ場所の変更前後を撮影。
- 所持品、倉庫、資金、寄贈、村の発展、章の進行、セーブを維持。
- 音楽とボス処理は今回の対象外。次工程はアユタヤの遺跡周辺。
- 完了報告は変更ファイル、確認結果、未確認事項を分けて記載。
