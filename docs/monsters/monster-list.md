# 全モンスター一覧（現状調査・2026年10月）

`node tools/monster-survey.js` が `js/data.js`・`js/story.js` から作った表です。手で書いた数値はありません。ゲームは変えていません。

- 「新しい探索」は、今始める探索（配置の版4）です。「以前の版」は、更新前から続いている探索だけで使います。
- 出現の%は、その階の出現表の中での割合です。章の偏り（bias）を入れた値です。
- 敵の数・追加の湧き・モンスターハウスは `docs/MONSTER_SURVEY.md` の「4. バランス」を見てください。
- 「仮」と書いた数値は、Claude が置いた調整案です。まだ確定していません。
- 想定レベル・推奨装備は、ゲームのデータにありません。なので **未設定** です。
