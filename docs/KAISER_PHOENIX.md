# カイザーフェニックス（大魔王バーンの火の鳥）（2026年10月）

ChatGPT 制作の火の鳥の絵をそのまま使っています。描き直しはしていません。

## 素材
- 元の素材：`assets/reference/kaiser-phoenix-v1/kaiser-phoenix.png`
  - 1254×1254、下向きに飛ぶ火の鳥です。
  - 背景は透過で、四隅は完全に透明でした。不透明な黒い画素はありません。
- ゲームで使う絵：`assets/fx/kaiser-phoenix.png`
  - 透明な余白を切り落とし、長い辺を320pxに縮小しました（320×313）。
  - 向きは下向きのままです。攻撃の向きに合わせて、ゲームの中で回します。
- 作り直すときは `python3 tools/make-kaiser-phoenix.py` を実行します。
- 画像のパスは `js/assets.js` の `fx.kaiserPhoenix` です。読み込めなければ、今までの炎の帯の演出になります。

## 演出（`js/fx.js` の `FX.draw.kphoenix`、間合いは `js/ui.js` の `UI.PHOENIX`）

| 段階 | 長さ | 中身 |
|---|---|---|
| ① 集まる | 0.32秒 | バーンの前（攻撃の向きへ0.6マス）に、小さな炎の光が集まる |
| ② 飛ぶ | 1マス0.095秒（0.30〜0.56秒） | 翼を広げた姿で、少し小さい所から大きくなって現れ、当たる所まで飛ぶ。薄い残像2つと、少しの火の粉を残す |
| ③ 当たる | 0.26秒 | 短い炎の閃光。火の鳥は少し広がりながら消える |

- 全体の長さは約0.88〜1.14秒です（4マスで0.96秒）。
- 羽ばたきの別の絵は使っていません。1枚の絵を、移動・拡大縮小・透明度だけで動かしています。
- 向きは、下・上・左右・斜めのどれでも、その方向へ絵を回します（絵の下向きを0度として回しています）。
- 翼を広げた幅は約2.2マスですが、見た目だけです。
- **当たる所**
  - たけが予告の列の上にいれば、たけのマスで当たります。
  - 外れたときは、列の端まで飛んで消えます。

## 戦いの仕様は変えていない
- 攻撃の範囲（予告の赤いマスの列）・威力（攻撃力×1.9）・よけ方（列の外へ出る）・間隔は、今までのままです。
- 当たりの判定もダメージの処理も、ゲーム側で1回だけです（`resolveCharge`）。演出は見た目だけです。
- **届いた時に合わせて見せるもの**
  - ダメージの数字・赤い点滅・痛い音。
  - HPゲージ（届くまでは当たる前のHPを出しています。`UI.hpHold`）。
  - よけたときの「ミス」。
- 届くまでは次の行動を受けつけません（連打で動かない）。
- このダメージで倒れたときは、当たるところを見せてから倒れた画面へ進みます。

## 確認（`tools/kaiser-phoenix-check.js`、30階の玉座の間で実際にボス戦。幅360・390・430）
81項目がすべて通りました。

- バーンの予告（赤いマス）のあと、次の行動で火の鳥が飛びます。
- 全体の長さは、4マスで0.96秒・斜め3マスで0.88秒・列の端までで1.14秒です。
- 向きは下・右・左上の斜め・上で確かめました。
- **当たったとき**
  - ダメージの数字は、届いた時刻の±40ミリ秒以内に出ます。
  - HPゲージも届いた時に減ります。HPは1回分だけ減ります。
- **列の外へよけたとき**
  - ダメージは無く「ミス」になります。見た目で当たりは広がりません。
- 届くまで連打しても、ターンは1回分しか進みません。
- **画面録画**（`docs/kaiser-phoenix-v1/`、幅390）
  - `kaiser-phoenix-battle-390.mp4`：下・右・斜め・上・よける の5回、そのままの速さ。
  - `kaiser-phoenix-down-slow.mp4`、`kaiser-phoenix-diag-slow.mp4`：半分の速さ。
