# 村の改修 v1：サイの店〜ヤナイ像の広場（2026年10月）

素材：`assets/village/`（受け取った個別の透過PNG 24枚と `manifest.json`）。
- 見本 `assets/reference/village-v1-reference.png` は雰囲気と配置の参考です。ゲームには貼っていません。
- 受け取った指示書は `docs/VILLAGE_V1_INSTRUCTIONS.md` にあります。

## 大きさの決め方
- 村は1マス32ドットです。スマホでは1ドット＝3ピクセル（幅360〜430）で表示します。
- **建物・小物**（店・像・木・花壇・屋台・ベンチ）は、素材の **2/3** の大きさで描きます（`TS.ASSETS.village.propScale`）。
  - 2/3 にすると、店の幅が今までの店（4マス＋余白）とほぼ同じになり、今の地図に収まります。
  - スマホ（3ピクセル）では素材の1ドットがちょうど2ピクセルになり、にじみません。
- **子供**（64×64、足元 32,60）と**猫**（32×32、足元 16,28）は、人物と同じ等倍です。
  - 子供の絵の高さは34ドットで、大人（約48ドット）の約7割です。
  - 猫は約20ドットで、子供より小さくなります。
- 置く位置は、素材の足元（manifest の anchor）を地図の足元にそろえます。

## 子供と猫（村だけ。戦わない）
| ID | 絵 | 場所 | 調べたとき |
|---|---|---|---|
| `play` | child_play | (12,11) 広場の脇 | 「きょうも冒険に行くの？」 |
| `book` | child_book | (8,11) 木陰のベンチの横（立ち姿のまま） | 「遺跡の本を読んでいるんだ。」 |
| `cat` | child_cat | (4,14) サイの店の近く（店先の猫のほうを向く） | 「この子、サイちゃんが大好きなんだよ。」 |
| `ginger` | cat_ginger | (2,14) サイの店先。ふだんは座り、ときどき丸くなる | 「にゃー。すりすりと寄ってきた。」 |
| `calico` | cat_calico | (5,13) 店の横で眠る | 「すうすう……気持ちよさそうに眠っている。」 |
| `black` | cat_black | 花壇の前 (7〜8, 14) を左右に短く歩く | 「にゃっ。しっぽをぴんと立てた。」 |

- **向き:** 子供の正面・右・背面は向きの静止画です。歩行のコマとしては使いません。たけが2マス以内に来ると、そちらを向きます（左は右の反転）。
- **黒猫の動き:** 位置をなめらかに動かす簡単な表現です（座る4秒 → 歩く1.6秒）。猫の歩くコマはありません。
- **動きの止め方:** 猫の動きは時刻だけで決め、タイマーは使いません。村の画面を離れると描かれず、アプリが裏に回ると止まります。
- **場所の扱い:** 決まった番号と場所で作るので、村を出入りしても、村の絵を作り直しても増えません。位置は保存しません。
- **当たり:** 立つマスは通れません（大人の人と同じ。黒猫は2マスとも）。
  - 店の前の横の道（y14〜16）は、どの列でも2マス以上あけています。
  - すべての施設の入口と像の前へ歩いて行けます。
- **タップ:** タップする範囲は絵の大きさに合わせた小さめの範囲です（子供 22×38、猫 24×22）。施設の担当の人が優先です。
  - タップすると、となりのマスまで歩いて話します（猫は調べます）。キー操作でぶつかっても話します。
  - お金・満腹度・探索のターンは変わりません。

## 変えていないもの
主人公やサイの絵、施設の解放条件、セーブの中身（村の配置は保存していない）、ボス・道具・音楽・章の進行。

## 残っている作業
- 地面のタイル（石畳・芝生・水面）は今までのコードの絵です。素材の細かさとは少し違います。
- 区画の外の建物（鍛冶屋・倉庫・展示室・復興本部・食堂）、ヤシの木、鉢、灯りは、今までのコードの絵のままです。
- 子供・猫の歩行アニメ（足を交互に動かすコマ）、猫の背面の絵はありません。
- 改修前後の比較は `node tools/village-shots.js 出力フォルダ` で、同じ状態・同じ位置から撮れます。

## 改修前後の比較
`docs/village-v1/` に、同じ村の状態・同じたけの位置・同じ画面の大きさで撮った「左：改修前／右：改修後」を置いています。
- 村の状態は2つです。`early` ははじめの村（第1章・施設なし）、`developed` は発展した村（第4章・施設と飾りすべて）です。
- たけの位置は3つです。`shop` は店の前 (3,15)、`plaza` は広場 (7,13)、`statue` は像の前 (9,14) です。
- 画面の幅は 390・360・430 です（スマホの縦向き。360・430は店の前だけ）。
- 撮り直しは `node tools/village-shots.js 出力フォルダ` です。
