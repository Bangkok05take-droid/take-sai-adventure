# ボスとの再戦（たけの日記）（2026年10月29日）

- **開く条件:** 大魔王バーンを倒したあと。こもれびの家（村の発展の「施設」）に「たけの日記」が出る。
- **選べるボス:** 倒したことのあるボス。クロコダイン・フレイザード・キルバーン・竜騎士バラン・ミストバーン・大魔王バーン＋真大魔王バーン（セット。真大魔王バーンを倒したあと）。竜魔神バランは選べない。
- **流れ:** 日記でボスを選ぶ → 再戦の出発画面（帰還の巻物を借りられる）→ そのボスの章のダンジョンを1階から（大魔王のローブなら21階から。ボスの階が21階より深いキルバーン・バラン・ミストバーン・大魔王バーンのセットだけ）。
  - 大魔王バーンのセット：30階の大魔王バーン → 連れ去るムービー・ティウの救援は無く、すぐ時空の亀裂 → 31・32階 → 33階の真大魔王バーン（着いたら目覚めのムービー）→ 帰還口。
- **強さ:** ボス部屋で戦いが始まるとき、たけの攻撃力・防御・最大HP（装備・料理こみ）に合わせて決め直す（再戦だけ。本編は変えない）。数値は `D.REMATCH`。
  - 防御＝たけの攻撃力×0.5、攻撃力＝たけの最大HP÷6＋たけの防御×0.7、HP＝たけの1回のダメージ×27。どれも本編の強さより下げない。
- **報酬:** 初回と同じ品のうち、持っていない品だけ（全部持っていれば黄金の象）。大魔王バーンは大魔王のローブ。真大魔王バーンは品なし。
- **物語:** 章は進まない。本編のボス前後の会話・撃破後ムービー（バラン・大魔王バーン）は出さない。登場ムービーは毎回（スキップ可）。
- **記録:** 日記に再戦で勝った回数（`V.rematchWins`）。
- コード：`js/game.js` の `G.rematch*`・`G.depart(…, { rematch })`、画面は `js/ui.js` の `openDiary`・`openDepart(rematch)`。テストは `tests/logic.test.js` の「ボスとの再戦」。
