# 敵の一覧（デザイン制作用の資料）

2026年10月時点のコードから書き出した一覧です。**仕様は変更していません**。
数値と出現階は `js/data.js` の `D.ENEMIES` と `D.floorFor()` を実際に動かして確かめた値です。行動は `js/game.js` の `enemyAct()` で確認しています。
絵の大きさは、ブラウザで読み込んだ絵を実際に測った値です。

- 一覧画像（通常の敵15種・2コマ）：[enemies_sheet.png](enemies_sheet.png)
- 参考（ボス）：[bosses_sheet.png](bosses_sheet.png)
- 一覧画像の作り直し：`node tools/make-catalog.js`（測った大きさは `catalog_info.json` に出る）

この資料での区別：

| 表示 | 意味 |
|---|---|
| **実装済み** | 今の冒険（章）で実際に出る |
| **コードにあるが未使用** | データと絵はあるが、今の冒険では出ない（以前の版の冒険の続きなどでだけ出る） |
| **今後の提案** | コードには無いもの（この資料の最後にまとめる） |

## 1. 通常の敵 15種（すべて実装済み）

### 1-1. 能力と出現階

- **出現階**は全章共通です。ただし最終章（第6章）だけは30〜35階があるので、深い階の敵がその先まで出ます。
- 各章のボスの階（第1章15階・第2章20階・第3章25階・第4章と第5章30階・最終章35階）には通常の敵は出ません（2026年10月から）。そのため、第1〜3章ではボスの階より深い階の敵は出ません。最終章の31〜34階は「大魔王の城」で、出る敵が別の表になります（魔王軍の騎士・魔界の小鬼・神殿の番兵・結晶ゴーレム・光の精）。
- HP・攻撃・経験値は、表の値から階ごとに上がります（`D.ENEMY_SCALE`：1階ごとにHP+12%・攻撃+8%・経験値+12%）。上がり始める階は `base`（無い敵は1階）です。章が進むと、さらに少し強くなります（`D.chapterMul`）。

補足（コードで確認できたこと）：
- **章ごとに出やすい敵**（`D.CHAPTERS[章].bias`。その階にもともと出る敵だけが増える）
  - 第1章：ガマ蛙×2、毒トカゲ×1.6、石ガメ×1.5、水クラゲ×1.3
  - 第2章：光の精×1.8、結晶ゴーレム×1.4、ヤミコウモリ×1.3
  - 第3章：金ぴかザル×2、ヤミコウモリ×1.5、吹き矢ザル×1.5
  - 第4章：石像の戦士×2、神殿の番兵×1.6、結晶ゴーレム×1.2
  - 第5章：苔の祈祷師×1.8、光の精×1.5、ヤミコウモリ×1.4
  - 最終章：神殿の番兵×1.4、結晶ゴーレム×1.2
- 石ガメが10〜15階に出ないのは、10〜15階の出現表に入っていないためです（`D.enemyTable`）。石像の戦士も10〜12階には出ません。
- **モンスターハウス**：6階以降のふつうの階で8%。その階の出現表から最大10体が眠った状態で出ます。
- **落とし物**：倒した通常の敵は12%でその階の道具を1つ落とします。
- **飛び道具の見た目**：吹き矢ザル・光の精・魔界の小鬼は、どれも同じ「小さな四角が飛ぶ」表示です（`js/render.js` の `dart`。色の指定が無いので同じ色）。ログは、吹き矢ザルが「吹き矢！」、光の精と魔界の小鬼はどちらも「光の矢！」です。魔界の小鬼の説明文（`tip`）には「火の玉」とありますが、火の玉の絵やログはありません。

### 1-2. 使っている画像（15種すべて仮画像）

| 項目 | 今の状態 |
|---|---|
| 画像の種類 | **すべてコードで描いた仮の絵**（`js/sprites.js` の `E.frog` など）。画像ファイルはありません（`assets/enemies/` フォルダはまだ無い） |
| 差し替え先 | `js/assets.js` の `TS.ASSETS.enemies`（今は空 `{}`）。書いた敵だけが画像に替わる仕組みはできている |
| キャンバス | 32×32（1マス＝32ドット） |
| 向き | **1方向だけ**（ほぼ正面）。左右反転・横向き・背面は無い。移動の向きで絵は変わらない |
| コマ | **2コマ**（コマ0・コマ1）。待機中に420ミリ秒ごと（ヤミコウモリは160ミリ秒ごと）に切り替わる。眠っているときはコマ0で止まる |
| 移動・攻撃・被弾・撃破のコマ | **専用のコマは無い**。絵は動かさず、描く位置を動かして表現している（下の表） |

コードで付けている動き（絵のコマではなく、描く位置や色の変化）：
- 移動中だけ：ガマ蛙は短く跳ぶ。石ガメは左右にゆれる。吹き矢ザル・金ぴかザルは小さく上下する。ほかの敵は位置が滑らかに動くだけ。
- 撃つ前（吹き矢ザル・光の精・魔界の小鬼）：一瞬のけぞって狙う。
- 全員：攻撃のときの踏み込み、被弾したときの白い点滅と揺れ、撃破で短く消える（240ミリ秒）。予告中は頭の上に「！」、眠り・鈍足は頭の上に印。
