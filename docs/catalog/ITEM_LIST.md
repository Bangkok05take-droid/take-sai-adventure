## 共通のきまり

**価格**
- **買値**：村のお店の値段（`price`）。値段は固定です。
- **売値**：村のお店で売るときの値段（`sell`）。
  - 鍛冶で強化した武器・盾は、+1ごとに15G上がります。
  - 杖は、回数が0のときだけ売値が3分の1になります。
  - 「売れない」は、`noSell` か貸出品です。

**床で拾う・敵が落とす**
- その階の道具の表から選ばれます。
- 敵が落とすのは、通常の敵を倒したとき12%の確率です。
- モンスターハウス（6階から）にも同じ表の道具が置かれます。
- 下の表の「拾える階」は、第1〜5章のふつうの階の値です。最終章は、31〜34階で表が別（大魔王の城）になります。

**ボスの階**
- 各章の30階と、最終章の35階では、やくそう・いのちの霊薬・特製お弁当・上やくそうが出ます。

**村のお店**
- お店に並ぶ品は、村の段階で増えます（`D.SHOP_STOCK`）。
  - 段階1（はじめ）：やくそう・甘いバナナ・木の盾・どうのつるぎ
  - 段階2（倉庫の拡張のあと）：上の品＋ねむり草・みとおしの巻物・気配察知の巻物
  - 段階3（鍛冶屋と屋台のあと）：上の品＋特製お弁当・いのちの霊薬・けむり玉・どくけしそう
- さらに、これまでに進んだ章の品が加わります（第1章：どんそくの粉、第2章：みずがみの護符、第3章：みやぶりの鏡、第4章：いかずちよけの護符、第5章：きりばらいの香）。

**謎の旅商人**
- 8階からのふつうの階に、14%の確率で出ます。
- 売るのは素材だけです。値段は基準の値段の±10%で、10G単位にそろえます。

**画像**
- 見本の絵：
  - `assets/items/list/○○.png`（一覧用 48×48）と `assets/items/floor/○○.png`（床に置いたとき 32×32）の2枚があります。
  - `js/assets.js` の `TS.ASSETS.items.map` で、どの道具に使うかを決めています。
  - デザイン見本 `assets/reference/` から切り出したものです。
- 2026年10月に追加した絵（18種）：
  - `assets/items-v2/○○.png`（一覧用 48×48）と `assets/items-v2/floor/○○.png`（床用 32×32）。
  - `js/assets.js` の `TS.ASSETS.items.byId` で、内部IDごとに登録しています。
- コードで描いた仮アイコン（今は、絵が読み込めなかったときの代わりだけ）：
  - `js/sprites.js` の `I.○○`（16×16）です。
  - 一覧では6倍、床では2倍に拡大して表示しています。

## 8-2. アクセサリー（4種。2026年10月追加）

## 8-3. 投げる（2026年10月追加）

- 道具欄と足元の画面に「投げる」。8方向を選ぶ（「やめる」なら道具もターンも減らない）。投げると1ターン。
- 直線上の最初の敵に必ず当たる。射程10マス。壁は通らず、斜めでも壁の角は抜けない。商人の手前で落ちる。
- 当たった道具はなくなる。外れたら止まった所に落ちる。そこに道具・階段などがあれば、壁を通らず2マス以内の空いた床へ。無ければ消える。
- 装備中の品（外してから投げる）と大切な物（願いの宝珠）は投げられない。
- 数値は `js/data.js` の `D.THROW` で調整する。

| 投げた物 | 当たった敵への効果 |
|---|---|
| ねむり草 | 10ターン眠る（ボスは3ターン。道具として使ったときと同じ） |
| どんそくの粉 | 15ターン鈍足（ボスは6ターン） |
| やくそう・上やくそう・いのちの霊薬 | 敵のHPが35・90・全回復（たけには効かない） |
| どくけしそう | 敵のHPが20回復 |
| けむり玉 | 敵が見えない離れた部屋へ飛ぶ（ボス・分身には効かず小さなダメージ） |
| 武器 | (4＋(攻撃力＋強化値)×2) を攻撃力として、通常の攻撃と同じ式で防御を引いたダメージ |
| そのほか（盾・お宝・素材・食料・護符・アクセサリー・杖・巻物） | 小さなダメージ＝2＋0.2×階（四捨五入。防御は無視）。杖の雷・巻物の効果・アクセサリーの効果は出ない |
