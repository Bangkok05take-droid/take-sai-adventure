# ボス部屋の画像の制作仕様（ChatGPT 向け・2026年10月20日）

全ボスの部屋を「画面の下の前室・通路から上へ進んで入り、奥のボスへ向かう」形にそろえます。
背景の絵が届いた部屋から順に、その絵に合わせた専用の地図（通れるマス）を作ります（通常バラン戦の `D.BARAN_ROOM` と同じやり方）。

## 共通の決まり
- **1マス＝50px**（通常バラン戦だけは 845/17≒49.7px。届いた絵に合わせたため）。キャラクターは1マスの絵で描くので、この倍率に合わせて表示します。
  - たけの身長 ≒ 73px（約1.5マス）、ボス（バランなど）の本体 ≒ 100px（約2マス）。
- **横 950px（19マス）・縦は下の表**。引き伸ばしはしません。届いた絵の座標と倍率をそのまま使います。
- **通れる床**と、**通れない所**（壁・柱・炎の台・玉座の壇・段差・縁の帯・洞窟の岩）を、はっきり描き分けてください。
  - 絵の床の升目は、ゲームのマスにしなくてかまいません（升目の大きさは自由）。
- **出入口は下だけ**です。左右・上や通路の脇に、通れそうな開口・扉・階段は描かないでください。
  - 上の段・階段は、壇の飾りとして描いてかまいません（通れない）。
- **絵の外は黒**になります。画面は絵の上下の端で止めているので、絵は縦いっぱいまで描いてください（いちばん下の行も岩や壁で埋める）。
- 帰還口（金の魔法陣）・報酬の宝箱・床の印（炎・氷・罠）は、ゲームが広間の床の上に描きます。絵には入れないでください。
- 玉座など、ボスの近くに置く大きな物は、別の透過PNGにすると大きさを後から調整できます（バランの玉座と同じ）。

## 部屋の型（広間15×15）
新しい部屋の基本の型です。絵の座標（px）で示します。

| 範囲 | マス（列・行） | 絵の座標（px） | 通れるか |
|---|---|---|---|
| 奥の壁・壇・玉座など | 行0〜9 | y0〜500 | 通れない |
| **広間**（戦う床） | 列2〜16・行10〜24（15×15） | x100〜850・y500〜1250 | 通れる |
| 広間の左右の縁 | 列0〜1・17〜18 | x0〜100・850〜950 | 通れない |
| **通路** | 列8〜10・行25〜31（3×7） | x400〜550・y1250〜1600 | 通れる |
| **前室** | 列7〜11・行32〜34（5×3） | x350〜600・y1600〜1750 | 通れる（最初の道具を置く） |
| 前室の出口側 | 列8〜10・行35〜36 | x400〜550・y1750〜1850 | 通れる |
| **入口**（たけが立つ所） | (9,36) | x450〜500・y1800〜1850 | — |
| いちばん下 | 行37 | y1850〜1900 | 通れない（岩・壁で埋める） |
| **ボスの最初の位置** | 広間の中央 (9,17) | x450〜500・y850〜900 | — |

- 画像の大きさ：**950×1900px**。
- **戦いが始まる所**：通路のいちばん上（行25）から広間（行24）へ入る1歩で、登場ムービー → 戦い（1回だけ）。
- **帰還口**：倒したあと、広間の中央にいちばん近い空いた床。
- 広間の広さを変えたい部屋（例：横に広い・縦に長い）は、制作の前に相談してください。地図はその絵に合わせて作れます（バランは15×17）。
