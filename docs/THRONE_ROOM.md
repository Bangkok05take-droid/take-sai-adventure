## マスとの対応（`js/data.js` の `D.THRONE_ROOM`）

- 絵の64pxを1マスとして敷きます。地図は横16マス・縦25マスです。
- 絵の床の升目（約74px）は1マスにしていません。中央の絨毯で左右の升目がずれているので、升目どおりにマスを決めると左右がそろわないためです。
- マスの区切りは、中央の通路（絨毯 x 450〜577）がちょうど2マスになる位置にしています。
  - 列 c は、絵の x = 64c + 1.5 から始まります。
  - 行 r は、絵の y = 64r − 44 から始まります。

| 場所 | マス | 絵の範囲 |
|---|---|---|
| 広間（戦う床） | x 2〜13・y 6〜18（12×13） | x 129〜897・y 340〜1172。床の内側です |
| 下の通路（入口） | x 7〜8・y 19〜23 | 絨毯の部分 |
| 入口（たけが立つ所） | (7, 23) | 通路のいちばん下 |
| 時空の亀裂 | (10, 6) | 広間のいちばん上の列、玉座の右手前。ムービーでも亀裂は玉座の右に開きます |

- **通れない所（壁）**
  - 玉座の段（玉座・柱・旗・上の炎の台）。
  - 左右の縁取りの帯と、そこに立つ炎の台・柱。
  - 通路の両脇の柱・炎の台。
  - 地図のいちばん下の行。
- 左右の縁取りの帯の内側にも、少し床が見えています（約0.6マス）。炎の台が立っている帯なので、通れる所には入れていません。

## 進み方

- この部屋は下の通路を上へ進んで入ります（2026年10月20日から、ほかのボス部屋も同じ下の入口。`docs/BARAN_ROOM_V1.md`）。
- 広間に一歩入ると、登場ムービーが流れて戦いが始まります。ボスと手下は広間の中だけを動きます。
- 玉座の後ろの下り階段はありません。

## 時空の亀裂

- 戦闘前は出しません。
- 大魔王バーンを倒したときに場所を決めて保存します（`run.crack`、`kind: 'throne30'`）。報酬のローブは亀裂のマスに置きません。
- 撃破後ムービー（`vearnTaken`）の間は画面に出しません。最後まで見た・スキップ・読み込み失敗のどれでも、同じ状態で出ます。
- 背景には焼きこんでいません。別の絵として描いています。
  - 足元のマスの下端にそろえて、約2.4マスの高さで立てます（上は玉座の段にかかります）。
  - ゆっくり明滅させています。
- 読み込み直しても消えません。報酬や救援も重なりません。
- 行き先は進行で切り替わります（`G.crackState`）。
  - 救援が終わるまで：入れません。
  - 真大魔王バーンを倒す前：31階へ進みます。
  - 倒したあと：隠しダンジョン「時空の狭間」の31階へ進みます（`docs/FINAL_V3_SETS.md`）。
- 以前の形の30階（更新前から続いている探索）では、玉座の後ろの位置に出ます。

## 描き方（`js/render.js`）

- 玉座の間では、タイルを描かずに背景の絵を敷きます（`drawThroneBg`）。
  - 見える範囲だけを転送します。
  - 細かい絵なので、ここだけなめらかに拡大します。
- 絵の下端（入口の通路の先）は、背景の色になじませています。
- 絵の中の炎の位置に、ゆらぐ明かりを重ねています。
