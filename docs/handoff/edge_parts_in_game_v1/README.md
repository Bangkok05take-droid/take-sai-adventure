## 不足している形
- 出っ張った角（4方向）：上と左（右）が床の壁のマス
- 左右の縁の終わり：縁が、通路の口の上の正面の壁の上で終わる所
- 下の縁の終わり：下の縁が、となりの正面の壁や通路の口で終わる所
- 部屋の上の角（レンガの回廊）：左右の縁が、3マスの高さの壁の上端に届く所
