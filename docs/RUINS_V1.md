# アユタヤの遺跡周辺 v1（2026年10月）

素材は1枚の見本です（`assets/reference/ayutthaya-ruins-v1.png`、透過、4つの部品）。このときの依頼には CLAUDE_INSTRUCTIONS.md が付いていなかったので、依頼の文と、これまでの素材の決まりに合わせて組み込みました。

## 素材の作り方（`python3 tools/extract-ruins.py`）
- 見本から4つの部品を切り出しました：赤レンガの塔（tower）、古い門（gate）、木の根が絡む壁（banyan_wall）、崩れた壁（broken_wall）。
- ふちの薄い半透明（透明度200未満）は消しました。見本の外側に見える赤茶のにじみがこれです。それ以外は不透明にしています。
- 面積の中央値で縮小し、村の大きさそのままの絵（`assets/village/ruins/`）にしました。ゲームでは整数倍で描くので、にじみません。描き直しはしていません。
- 大きさは次のとおりです。
  - 門：0.25倍で、160×109。開口（約26ドット）を人1人が通れる幅にしました。
  - 塔：0.17倍で、82×116。寺院の段の上に収まり、地図の上の端で切れない高さにしました。
  - 壁：0.2倍で、根の壁が127×92、崩れた壁が115×62。
