# たけとサイの大冒険 〜アユタヤの夢見る遺跡〜

スマホのブラウザで遊べる、見下ろし型・ターン制のダンジョン探索ゲームです（静的な HTML/CSS/JavaScript のみ。サーバー・ログイン不要）。

- 大魔王に滅ぼされた村。師匠ヤナイが命と引きかえに大魔王を35階へ封じた。弟子の勇者たけとサイが、遺跡に挑みながら村を立て直します。
- **章立て**：各章は1階から始まり、30階でその章のボスが待ちます。倒すと報酬と帰還口が出て、村へ帰ると章クリアの会話と次の章へ。
  - 第1章 クロコダイン／第2章 フレイザード／第3章 キルバーン／第4章 バラン／第5章 ミストバーン
  - 最終章：第5章クリア後に解放。31〜35階が開き、35階で大魔王バーン → 真大魔王バーン。勝って帰るとエンディング。
  - 途中で帰還・力尽きた場合は同じ章のまま。クリア済みの章は繰り返しません。クリア後も探索・収集・村の発展は続けられます。
- 3階ごとに帰還の碑があります。章が進むほど敵が少しずつ強くなり、章ごとに出る敵・道具・ボス対策品（サイの店にも並ぶ）が変わります。
- 持ち帰ったお金・お宝・素材で、倉庫・鍛冶屋・食堂・展示室・村の飾りを整えて再挑戦します。
- 村は歩ける1画面です。地面をタップするとたけが歩き、サイ（店）・コイ（鍛冶屋）・モッ（村の発展）・ワーン（食堂）・ティウ（出発）や建物をタップすると、その前まで歩いて施設が開きます（下のボタンからもすぐ開けます。PCは矢印キー）。広場のマスターヤナイの像に話しかけると、師匠の言葉を思い出せます。
- 部屋は四角、通路は幅1マス。地下6階以降ではまれに敵とお宝の多い「モンスターハウス」があります。
- 持ち物は15個まで（装備中の品も含む）。

## 遊び方
- **方向ボタン（3×3）**：8方向に移動。短く押すと1歩、押し続けると約0.3秒後から連続移動（約170ms/歩）。指を離すと即停止。敵の方向へ動くと攻撃（押しっぱなしで攻撃は繰り返さない）。壁の角越しの斜め移動・攻撃はできない（敵も同じ）。
- **中央の「向き」**：タップでオン/オフ。オンの間は方向ボタンで向きだけ変わる（ターン・敵・満腹度は進まない）。杖はこの向きに使う。
- **「向き」の長押し（0.4秒）**：休息＝連続足踏み。通常の待機と同じルールで1ターンずつ進み、自然回復する。HP全回復・敵・ダメージ・満腹度・毒・指を離すなどで停止。
- **足踏み**：その場で1ターン待つ。
- **ダッシュ**：オンにして押し続けると約85ms/マスで連続移動（1マス1ターン）。新しい敵・被ダメージ・隣の敵・壁・分かれ道・道具・階段・帰還地点・新たな危険域で自動停止し、理由を表示。押し直すと再開。
- **足元**（階段・拾う・帰還）／**道具**（使う・まく・投げる・読む・装備・置く・整理。杖は8方向から向きを選んで振る）／**メニュー**。倉庫と村の持ち物にも「整理」ボタン。
- PC：矢印キー/WASD、斜めは Q・E・Z・C（テンキー 7・9・1・3）、足踏み=スペース、向き=F、ダッシュ切替=X、道具=I、メニュー=Esc。

タイトルは、専用ロゴ `assets/logo.png` と、見本 `assets/title-characters.png` から切り抜いた人物 `assets/title-chars.webp` を、夕暮れの遺跡と水辺の景色（画面側で描画）に重ねた一枚絵です（作り方は `assets/README.md`）。アイテム名の変更前後の対応は [docs/ITEM_NAMES.md](docs/ITEM_NAMES.md) を参照。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `js/data.js` | 敵・道具・階層・施設・料理・価格などの**調整用数値** |
| `js/story.js` | 章の構成・報酬・登場人物（たけ・サイ・ヤナイ・コイ・モッ・ワーン・ティウ）・会話文 |
| `js/bossai.js` | 各ボスの行動（予告→発動。突進・床の炎/氷・分身と罠・雷・霧と拘束・最終決戦） |
| `js/assets.js` | 画像素材の一覧（デザイン見本から作った人物・道具の画像、差し替え先）。画像の基準は `assets/README.md` |
| `js/rng.js` | セーブ可能なシード付き乱数 |
| `js/dungeon.js` | ダンジョン生成 |
| `js/game.js` | ゲーム処理（ターン・戦闘・敵AI・道具・ダッシュ・村の経済）。表示と独立 |
| `js/save.js` | localStorage 保存（バージョン付き・旧データの移行あり） |
| `js/sprites.js` | オリジナルのドット絵（キャラクター・敵・道具。陰影つきドット絵ペインターでコードから描画） |
| `js/tiles.js` | ダンジョンの地形（地域ごとの床・壁・水辺・部屋の見せ場） |
| `js/village.js` | 歩ける村（横20×縦26マス。建物・広場・水路・人物の配置、道さがし。発展と章で変化） |
| `tools/` | デザイン見本から素材を作る道具（`extract-art.py` 人物、`extract-items.py` 道具。Python と Pillow） |
| `js/render.js` | ダンジョン・村の描画 |
| `js/audio.js` | 効果音・BGM（WebAudioで合成） |
| `js/ui.js` | 画面・入力・メニュー |

## セーブデータ
- 保存キー `takeSaiAdventure.save`、形式バージョン 3。
- 章の進行は `village.story`（現在の章・各ボスの撃破・報酬受け取り・帰還イベント・最終決戦の段階・エンディング）に別々に保存。
  35階の最終決戦は段階（大魔王戦→準備→真大魔王戦）を保存するので、再読み込みしても回復や変身は繰り返しません。
- 旧データは自動で移行：所持品・倉庫・資金・装備・村の施設を引き継ぎます。
  - v2 の「30階クリア」は「旧版のクリア記録」として残り、新しい章は第1章から始まります（全章クリア扱いにはなりません）。旧「願いの宝珠」は「夢見の冠」になります。
  - 更新時に探索中だった冒険は、その地形のまま旧ルールで続けられ、村へ戻った後から章のルールになります。
  - v1 の「10階クリア」も旧記録として残ります。

## テスト
```sh
node tests/logic.test.js          # ゲーム処理の自動テスト（30階×200シードの生成、8方向・ダッシュ・敵AI・経済・移行など）
node tests/e2e.test.js [保存先]   # Playwright でスマホ画面を操作するテスト（/take-sai-adventure/ サブパスで配信）
node tests/balance.js [回数]      # 簡易AIによる到達階・収入の参考値
node tests/serve.js 8080          # http://localhost:8080/take-sai-adventure/ で確認
node tests/capture.js [保存先]    # 見た目の確認用スクリーンショット（タイトル・村・メニュー・各地域）
node tests/capture-bosses.js [保存先]  # 各章のボス戦と最終決戦の準備画面のスクリーンショット
```

## GitHub Pages で公開
リポジトリの Settings → Pages → 「Deploy from a branch」で公開したいブランチと `/ (root)` を選んで保存すると、
`https://<ユーザー名>.github.io/take-sai-adventure/` で遊べます（相対パスのみ使用、`.nojekyll` 同梱）。
