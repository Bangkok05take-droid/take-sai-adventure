# たけとサイの大冒険 〜アユタヤの夢見る遺跡〜

スマホのブラウザで遊べる、見下ろし型・ターン制のダンジョン探索ゲームです（静的な HTML/CSS/JavaScript のみ。サーバー・ログイン不要）。

- たけが遺跡（地下30階）を探索し、サイが村のお店で帰りを待ちます。
- 10階・20階に中ボス、30階に最終ボスと「願いの宝珠」。3階ごとに帰還の碑があります。
- 持ち帰ったお金・お宝・素材で、倉庫・鍛冶屋・食堂・展示室・村の飾りを整えて再挑戦します。

## 遊び方
- **方向ボタン（3×3）**：8方向に移動。短く押すと1歩、押し続けると約0.3秒後から連続移動（約170ms/歩）。指を離すと即停止。敵の方向へ動くと攻撃（押しっぱなしで攻撃は繰り返さない）。壁の角越しの斜め移動・攻撃はできない（敵も同じ）。
- **中央の「向き」**：タップでオン/オフ。オンの間は方向ボタンで向きだけ変わる（ターン・敵・満腹度は進まない）。杖はこの向きに使う。
- **「向き」の長押し（0.4秒）**：休息＝連続足踏み。通常の待機と同じルールで1ターンずつ進み、自然回復する。HP全回復・敵・ダメージ・満腹度・毒・指を離すなどで停止。
- **足踏み**：その場で1ターン待つ。
- **ダッシュ**：オンにして押し続けると約85ms/マスで連続移動（1マス1ターン）。新しい敵・被ダメージ・隣の敵・壁・分かれ道・道具・階段・帰還地点・新たな危険域で自動停止し、理由を表示。押し直すと再開。
- **足元**（階段・拾う・帰還）／**道具**（使う・装備・置く・整理）／**メニュー**。倉庫と村の持ち物にも「整理」ボタン。
- PC：矢印キー/WASD、斜めは Q・E・Z・C（テンキー 7・9・1・3）、足踏み=スペース、向き=F、ダッシュ切替=X、道具=I、メニュー=Esc。

タイトルの人物イラストは見本 `assets/title-characters.png` から作った `assets/title-art.jpg`（作り方は `assets/README.md`）。アイテム名の変更前後の対応は [docs/ITEM_NAMES.md](docs/ITEM_NAMES.md) を参照。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `js/data.js` | 敵・道具・階層・施設・料理・価格などの**調整用数値** |
| `js/rng.js` | セーブ可能なシード付き乱数 |
| `js/dungeon.js` | ダンジョン生成 |
| `js/game.js` | ゲーム処理（ターン・戦闘・敵AI・道具・ダッシュ・村の経済）。表示と独立 |
| `js/save.js` | localStorage 保存（バージョン付き・旧データの移行あり） |
| `js/sprites.js` | オリジナルのドット絵（陰影つきドット絵ペインターでコードから描画） |
| `js/render.js` | ダンジョン・村の描画 |
| `js/audio.js` | 効果音・BGM（WebAudioで合成） |
| `js/ui.js` | 画面・入力・メニュー |

## セーブデータ
- 保存キー `takeSaiAdventure.save`、形式バージョン 2。
- 旧バージョン（v1）のデータは自動で移行：所持品・倉庫・資金・村の発展・探索途中を引き継ぎます。
  以前の「10階クリア」は旧記録として残り、30階の新しい目標とは区別されます。

## テスト
```sh
node tests/logic.test.js          # ゲーム処理の自動テスト（30階×200シードの生成、8方向・ダッシュ・敵AI・経済・移行など）
node tests/e2e.test.js [保存先]   # Playwright でスマホ画面を操作するテスト（/take-sai-adventure/ サブパスで配信）
node tests/balance.js [回数]      # 簡易AIによる到達階・収入の参考値
node tests/serve.js 8080          # http://localhost:8080/take-sai-adventure/ で確認
```

## GitHub Pages で公開
リポジトリの Settings → Pages → 「Deploy from a branch」で公開したいブランチと `/ (root)` を選んで保存すると、
`https://<ユーザー名>.github.io/take-sai-adventure/` で遊べます（相対パスのみ使用、`.nojekyll` 同梱）。
