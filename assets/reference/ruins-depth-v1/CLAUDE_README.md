# 地下の遺跡：奥行き表現 v1

## 承認済みの方向性
ユーザーは approved_concept.png の見た目を承認しました。黒い余白を壁柄で埋める前案を置き換え、暗い洞窟の奥に、床を支える外壁と支柱が下へ伸びる表現を作ります。対象は通常階の地下の遺跡7〜14階だけです。
完成イメージの人物・部屋形状・床マス数は参考であり、ゲームのキャラクターや地形をこの絵に合わせて変更しないでください。前案の「背景1枚だけ」「全部を60%暗くする」は今回の完成条件ではありません。

- assets/foundation_wall.png：床端から下へ続く正面の外壁。透明PNG。横に並べる候補。全方向へ回転して使わない。

生成素材のため、繰り返しの継ぎ目・縮小時の見え方はプレビューで調整が必要です。画像の読込確認は素材側で行っていますが、ゲーム内での検証はまだありません。

## 描画方針
1. カメラではなく地図座標に固定した岩盤背景を最背面に敷く。未探索の地形と無関係の絵だけを表示する。
2. 探索済みの床と周囲の既知の壁から、見せてよい外周だけを取得する。未探索の床や壁の配置に応じて背景・柱・外壁の長さを変えない。
3. 外周の画面下向きの辺から、正面外壁を下方向へ伸ばす。初期案は高さ3マス、横幅2マス単位。近隣の探索済みの床・壁・通路は後から上に描き、外壁が通路を塞いで見えないようにする。床のない場所でのみ外壁が見える構成にする。
4. 左右の辺は縁と細い暗い側面・落ち影でつなぐ。正面外壁を90度回転すると石積みと光が不自然になるため禁止。素材が足りなければ短い側面の仮処理でまず全体を比較し、必要な専用側面素材の形と寸法をこちらへ返す。
5. 支柱は同じ外周に3〜5マス程度の間隔で控えめに配置。柱の頭を外壁の上端に合わせ、床内へ突出させない。配置は地図と固定シードで安定させ、フレームごとに変えない。
6. 描画順は背景→下へ伸びる外壁・支柱・その影→既存地形→アイテム・キャラクター・予告。外壁の下端は薄い霧またはアルファでなじませる。霧で床を覆わない。
7. 地図外にも同じ背景を連続させる。地図境界に明暗の四角い線を作らない。探索済みで今見えていない地形の既存の暗さは維持する。
8. 岩盤は暗く、外壁はそれより少し明るく、歩く床が最も読みやすい明度にする。素材は既に暗いので、一律60%減光を重ねず実画面で決める。火や霧のアニメーションは初版では不要。

## 制約と確認
- 地図・通行判定・視界・敵・強さ・階数・セーブ形式は変えない。既存のほかの地域とボス部屋は維持。
- 外壁の終端や柱の有無で未探索地形が推測できないことを確認する。同じ既知地形で未探索地形だけ異なる場合も装飾が変わらないようにする。
- 床が隣接する狭い箇所、1マス通路、内角、上下に並ぶ部屋で重なりを確認する。隠れた地形を参照して外壁を短くする方法では解決しない。
- 初版は静止背景と外壁のみ、必要な範囲の描画・キャッシュでスマホ負荷を抑える。
- 承認画像のような奥行きを目標にするが、ランダム地形の全箇所で同じ長さの崖が描けるわけではない。狭い箇所は歩ける床の読みやすさを優先する。
