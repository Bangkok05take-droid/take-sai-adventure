# 水没した古代都市：薄い壁の補修 sunken_thin_v1

A案：地形・当たり判定を維持。適用は水没した古代都市（16〜19階）のみ。
他地域は同じ分類・寸法の仕組みを使えますが、この青緑の素材をそのまま流用しないでください。

## 納品物
assets/：42 PNG。1マス32px、すべて等倍で描画。
assembly_preview_3x.png：既存の床と納品素材を並べた3倍拡大見本。実ゲーム画面ではありません。
parts_preview.png：端の形と短い壁の一覧。
reference/source_atlas.png：内蔵imagegenで作成した原画。ゲームへ直接貼らずassets/を使います。
generation_prompt.txt：生成指示。仕上げは指定寸法への切り出し、縮小、接続端の共通化です。

## 1. 横の低い壁 low_wall
上下とも床の壁マスを32×32の一枚で描きます。天板・壁面・水路を一枚の中に収めています。
low_wall_h0..3：連続部。low_wall_left_h0..3：左端。low_wall_right_h0..3：右端。
low_wall_single_h0..3：1マスだけ。左右両方が閉じています。
位相h=x%4。端の有無は横方向で同じ低い壁が続くかを調べて決めます。
通常壁への接続端は、露出した終端と区別してください。端の面を通常壁に二重に重ねないでください。

## 2. 縦の薄い壁 pillar_v
左右とも床の壁マスを32×32の一枚で描きます。中央は一体の広い天板です。
pillar_v_v0..3：連続部。pillar_v_top_v0..3：上端。pillar_v_bottom_v0..3：下端。
pillar_v_single_v0..3：1マスだけ。上下両方が閉じています。
この新しい一体型素材はv=y%4で選択します。左右のedgeを2本合わせた素材ではありません。
従来のedge_left y%4・edge_right y%2は通常壁にだけ適用し、この部品には適用しません。
左右と上下すべて床の孤立マスはlow_wall_singleを優先して、一度だけ描きます。

## 3. 幅の短い正面の壁
short_wall_1：32×96（幅1マス、高さ3マス）。
short_wall_2：64×96（幅2マス、高さ3マス）。閉じた波模様の石壁。
ここでの1・2は幅です。高さが1・2マスしか取れない場所へ96pxの絵を押し込まないでください。
3マスの高さを確保できる短い壁列専用。下端を床境界へ合わせ、既存のマス内描画・床を覆わない制御を維持。
左右に完結した柱があるため、孤立した短い壁列に使います。長い壁列の余りに差し込む場合は、柱が二重にならないか別途確認してください。無条件にwall_narrowを全置換しません。

## 描画順・競合防止
専用部品を描くマスでは、通常のedge_left/right/bottom、通常角・end_*、正面壁の切れ端を重ねて描かないでください。
優先順：孤立壁→上下床のlow_wall→左右床のpillar_v→高さが十分な幅1/2のshort_wall→従来描画。
判定には既存の実地形を使いますが、描画可否は既存の探索・視界ルールに従ってください。未探索の部屋を見せないでください。
上下左右の接続判定は既存の壁配置と照合。T字・曲がり・通常壁との境界で条件が重なる場合は、一枚に決めてください。複数の専用部品の重ね貼りで解決しないでください。
今回の32px素材に、既存の『上の帯24px＋足元8px』加工や中段省略をもう一度適用しないでください。
高さ2マスの壁で専用条件に該当しないものは既存処理を維持。本ZIPはあらゆる接続形状の自動タイルを網羅したものではありません。

## 位相とファイル名
assets/の末尾hN/vNなしファイルは位相0の代表です。
横連続部の左右2px、縦連続部の上下2pxは全位相で共通。異なる位相を並べても接続端が一致することを検証済み。
角・通常帯は今回変更しません。旧sunken_match_v1の素材・位相を維持してください。

## ゲーム内確認
添付で指摘された3か所を同じ地形で比較してください。地図生成を変えないこと。
横連続／縦連続／1マス単独／上下左右の終端／通常壁につながる端／短い正面壁を確認。
実寸と幅390で、壁と床の区別、通行との一致、赤い予告、探索前後の表示を確認。
ほかの3地域に適用済みの『中段省略』は今回の素材差し替えと分離し、共通描画変更による見た目の後退を確認してください。
納品側ではPNG寸法・読込・全位相接続端の一致を検証済み。実ゲーム内は未確認です。
まず水没した古代都市でプレビューを出し、他地域への展開はこの形が確認できてから行います。
