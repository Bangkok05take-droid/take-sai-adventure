# レンガの回廊・承認図との一致確認用 v2

今回は1〜3階だけの先行実装用資料。新しい承認図 approved_board.png が目標。
旧 dungeon_part3.zip の簡素な壁デザインは不採用。ほかの階へまだ展開しない。
assetsは承認画像から直接切り出したPNG。assembled_preview.pngは同じ部品だけで組んだローカル見本で、実ゲーム画面ではない。
原画の解像度は小さいため、この見本を超える拡大精細さは保証しない。別の絵へ勝手に置換せず必要なら原画再制作を依頼。

## Claudeへ
1. 現行の床・壁・角・装飾描画を調べ、1〜3階のみプレビューで組み込む。
2. 床の基本はfloor_4x4を4×4マスの128pxとして使う。部屋/通路で模様と倍率を変えない。柄が4マス単位で繰り返すこと、目地がやや強いことは見本でも確認できる。ゲーム内で目立つ場合は色や目地の再調整が必要。無断で別柄を混ぜない。
3. wall_archは4マス幅×3マス高、wall_bannerは2マス幅×3マス高、wall_narrowは1マス幅×3マス高の候補。底を床との境界に合わせる。これは原画の特徴を残すための候補寸法で、現行の壁領域へ無条件で押し込む指定ではない。
4. 壁の描画高さが現行と合わないときは、床・隣室・探索表示を覆わないようにする。アーチや旗を大きく押し潰す前に必要寸法をChatGPTへ返す。地形を変更して合わせない。
5. 旗・灯り・浅い柱は壁画像に含まれる。追加の装飾画像を重ねない。壁を単なる無地のレンガへ差し替えない。
6. 縁は壁側に置く。左右の短辺・角は現行接続方式と合わせて確認する。本パックのcorner_bottom_leftは参考1点で、全方向の完成オートタイルセットではない。内角/端部で足りない形は寸法と接続先を提示する。
7. 部屋外は黒。追加背景・下向きの外壁・支柱は復活させない。
8. ランダム地形の大小の部屋、1マス通路、奇数長壁、隣接部屋で、通れるマスが絵と一致することを確認。隠れた地形や敵を描画しない。
9. たけ・敵・アイテム・赤い予告を載せた実画面を360/390/430で確認。通常倍率で承認図と比較する。見本の単独部屋だけで完成判定しない。
10. 出力は承認図/ローカル見本/実ゲームの比較画像と、残る判断点だけ。テスト件数のみで見た目を合格扱いしない。

## 進め方
ユーザーはこの見た目での実装を依頼済み。まず1地域の忠実度を実画面で確認する。見た目を大きく変える必要があれば画像で確認する。
ゲームのリポジトリはこの素材制作環境から編集していない。本番反映の有無はClaudeが明示する。
7地域の階数は承認図通り。今回のパックはレンガのみ。他の地域のパーツはこの接続・サイズ確認を基準に制作する。

## 検証
元画像はbuilt-in imagegen生成の承認図。今回は矩形切り出し・リサイズ・配置だけ。再生成や描き直しはしていない。
PNG読込とZIP整合性、部品を組んだ見本を目視確認。ゲーム内接続・当たり判定・端末検証は未実施。
