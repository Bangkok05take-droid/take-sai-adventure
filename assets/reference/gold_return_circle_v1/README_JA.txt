ボス撃破後の帰還ワープ：金の魔法陣

素材: gold_circle_64/96/128.png。同一絵の幅違い、RGBA透過。64px版を小表示の基準に使用。
用途: 既存のボス撃破後に出る村への帰還口の見た目を置換。時空の亀裂、本編31階への転送、隠しダンジョン入口、通常階段には適用しない。帰還口のない戦闘に追加しない。

表示:
・足元の床に横長の魔法陣。画像中心を帰還マス中心へ合わせる。
・床の上、アイテムとキャラクターの下に描画。表示幅は約1.3マスを初期値にし、画面で調整。操作判定は従来の1マス。
・既存の渦巻き表示は消し、二重に描かない。
・静止画の上に演出を足す。楕円画像を画面上で回転させない（床から起き上がって見えるため）。

任意演出を任されたための今回のデザイン指定:
出現: 0.45秒で透明→表示、倍率0.8→1.0。金の粒が少量浮上。
待機: 2秒周期で不透明度0.7〜1.0へ緩く明滅。小さな金色の粒4〜6個が上へ流れ消える。床や敵を隠す大きな発光は不要。
帰還決定: 現在の帰還確認がある場合はそれを維持し、承諾後に演出開始。
0〜0.25秒: 魔法陣が明るくなる。
0.25〜0.65秒: たけを包む細い半透明の金色の光柱と上昇粒子、たけが薄くなる。
0.65〜0.95秒: 黒へ暗転し、既存の帰還処理へ接続。村で0.35秒フェードイン。
光は金・クリーム色。白一色の強いフラッシュや連続点滅は使わない。

挙動:
この更新は素材と演出のみ。帰還先、報酬、持ち物回収、進行フラグ、条件は変えない。
演出中は入力・敵・空腹などのゲーム進行を停止。演出終了と帰還処理を1回だけ実行。
演出の失敗・再読み込みで操作不能や二重報酬を起こさない。既存の保存と帰還処理へ統合し、描画ループから帰還処理を呼ばない。

確認: スマホ幅360/390/430で床に見えること、たけが魔法陣より前に描かれること、帰還先と報酬が従来通りであること。短い動画を返す。
