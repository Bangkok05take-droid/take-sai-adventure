# 通常モンスター15種・基本動作素材 v1

## 中身
各フォルダ source.png=生成原寸、sheet.png=384x96透過シート、00〜03.png=96x96透過個別コマ。
左から待機A・待機B・技準備・技発動。ホイミスライムは回復、メタルスライムは逃走、おどるほうせきは盗み。
15種類×4コマ=60コマ。単方向の基本動作素材であり、四方向歩行・被弾・死亡・専用防御コマは含まない。

## サイズ
うごくせきぞう・ゴーレム・あくまのきしは待機絵の不透明範囲の高さ64px。残り12種類40px。
96pxの透明キャンバス全体をキャラクターの身長として扱わない。
この64pxはたけの既存52x64画像を基準にした暫定書き出し基準。
実際のたけの不透明本体の描画高さを測り、大型3体=1.0倍、小型12体=0.625倍に全コマ共通倍率で調整する。
影や技の光、武器の振り上げを本体サイズに含めて再拡大しない。足元アンカー48,84。
画像の占有は変わってもゲーム内の位置・当たり判定は従来通り1マス。

## 組み込み
manifest.jsonにコマ矩形と状態名。nearest-neighbor、imageSmoothingEnabled=false。
待機A/Bを繰り返し、技は準備→発動→待機。再生時間は仮に待機各350ms、準備140ms、発動120msから実機で調整。
描画コマ変更からダメージ・回復・盗み判定を実行しない。既存のゲーム進行イベントに描画を追従させ、判定は1回だけ。
火球・矢・斬撃が絵に含まれるコマがあるため、既存エフェクトとの二重表示を確認。
各コマは同倍率で縮小したが、生成元のポーズや左右の向きには揺れがある。実装前に実機サイズで動きを確認すること。
あくまのきしの専用防御ポーズはこの基本セットには未収録。待機の仮使用をする場合は未完成として明示。
数値・敵AI・出現階層をこの画像差し替えだけで変更しない。変更済みの行動仕様は別途実装。
