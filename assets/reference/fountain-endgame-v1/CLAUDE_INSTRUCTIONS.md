# 噴水の改修素材と次期構想

今すぐの実装対象は噴水と像の発展項目です。PLAN.mdの隠しダンジョン・装備効果はユーザーの企画メモです。未確定部分を勝手に実装せず保管してください。

## 噴水
assets/fountain-spray.pngはChatGPT制作の透過水流素材。既存の噴水本体はそのまま使い、現在の上部の小さな水滴表現を置き換える。新しい本体を描き直さない。
fountain-overlay.jsはChatGPTが指定した水の描画・動きの実装例です。素材の噴出口（下端中央）を既存噴水の上部ノズルに合わせる。表示幅は噴水の外側水盤幅の0.46倍、初期不透明度0.82。石の本体は一切揺らさない。既存の下段へ落ちる水は残す。水面上にだけ波紋が出るよう水盤クリップを使い、前面の石縁は最後に描画する。
コードには小さな水流の伸縮と、水盤内に広がる楕円波紋を用意。位置はワールド座標で与え、カメラ変換を二重適用しない。時間は既存の描画ループから渡し、新たな常駐タイマーを増やさない。
再デザインや過剰な粒子は追加しない。素材位置の微調整は既存の噴水座標に合わせてよい。スマホでの重なりと動きを確認して短い動画を報告する。

## マスターヤナイの像
「黄金の門」の発展項目を「マスターヤナイの像」に変更。価格・解放条件を引き継ぐ。既存の像画像を使用し、購入前は像・台座・ラベル・当たり判定なし、購入後に現在の場所へ設置。
旧セーブの黄金の門購入済みは像建設済みへ移行し、追加料金なし。未購入なら像は非表示。旧来の初期配置の有無から購入済みと誤判定しない。資金・他施設・進行を維持。

## 盾のデザイン案
assets/dragonic-aura-shield.pngは裏ボス報酬用の新規デザイン。盾の性能とセット効果は未確定。今回の噴水作業に混ぜて配布・装備効果を実装しない。

噴水と像の変更を確認し、いつものブランチへコミットして通常のプッシュ。確認済みと未確認事項を分けて報告してください。ゲーム内表示はこのZIPでは未検証です。
