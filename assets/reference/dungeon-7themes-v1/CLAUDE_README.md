## Claudeへの依頼
このZIPの画像と階層表を使い、通常ダンジョンの背景差し替えを進めてください。
これは画像生成で作成した素材原画7枚です。ゲーム用に切り出し・接続確認済みの完成タイルセットではありません。コードの実装・動作確認はChatGPT側では行っていません。

## 画像の使い方と制限
- 原画を無加工・原寸で収録。透過状態と画像サイズはmanifest.jsonに記載。
- 各シートは上から床の柄違い、壁、角、装飾を想定しています。ただし生成画像なので、等分切り出しで全パーツが正確に分離できる保証はありません。
- 壁は全方位の描き分けが揃っていません。角の一部は斜め視点です。単純な回転・機械的な4×4分割でそのまま接続できるとは扱わないでください。
- 床の端には透明余白や縁があり、シームレスな繰り返しは未検証です。床の内部を切り出して敷き詰め確認し、必要な修正箇所は画像に印をつけて報告してください。
- 水没都市の水、柱、瓦礫などは背景装飾です。水地形や障害物判定を新設しないでください。
- 原画は残し、加工・縮小した実装用素材は別フォルダに保存してください。

## 実装の進め方
1. 現在の1マスの寸法、床と壁の描画方法、通路幅、章ごとの背景割り当てを確認。
2. まずレンガの回廊で床・壁・角・通路の接続プレビューを作り、キャラクターと攻撃予告の視認性を確認。
3. 使用できる部分を素材化し、足りない壁の向きや角、継ぎ目を明示。無理に伸ばして地形へ合わせない。
4. 同じ方法で残る6地域を組み込み、360・390・430幅で部屋、細い通路、四隅、床の道具を確認。
5. 素材不足は仮表示と完成部分を分けて報告。実機未確認ならその旨を記載。

敵の数値・出現率・ドロップ・部屋の生成や当たり判定・ボス部屋・ボス階・物語・亀裂の行き先は変更対象ではありません。背景のために通れる場所を勝手に増減しないでください。
