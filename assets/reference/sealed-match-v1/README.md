# 封印の最深部 26〜29階 — sealed_match_v1

1マス32px。assets/・edge_fit/・ends_fit/のPNGはすべてゲームで等倍描画する完成サイズです。
背景は暗い単色。外景・下へ伸びる外壁・支柱はありません。

## 見本
- assembly_preview_2x.png：納品PNGを組み合わせた完成見本。2倍の最近傍拡大。実ゲームのスクリーンショットではありません。
- connections_2x.png：各壁と、左右の縦終端の接続見本（代表位相v0）。
- reference/approved_reference.png：以前の承認図の封印の最深部部分。今回は紫の石壁・封印紋・鎖・ルーンで構成しています。
- reference/source_atlas.png：今回の生成原画。直接ゲームへ貼らず、切り出し済みPNGを使ってください。
新しい完成見本自体のゲーム上の承認はまだです。まず組み込みプレビューを提示してください。

## 基本素材
- floor_4x4.png：128×128、1種類。x%4/y%4で32pxずつ使用。通路も同じ。各マスごとの柄のランダム切替は禁止。
- wall_chains：96×96、二重の鎖。
- wall_seal：96×96、円形の封印紋と紫の灯り。
- wall_runes：96×96、ルーンと紫の灯り。
- wall_narrow：32×96、閉じた石壁。
正面の壁は高さ96px、下端を床との境目に合わせます。既存の壁の描画範囲制御を使い、隣室・通路を隠さないでください。

## 壁の並び
壁列の左端から chains(3) → seal(3) → runes(3) の順に、入る限り並べます。
次の部品が入らない時は、残り3マスならseal、残り2マスならnarrow×2、1マスならnarrowで埋めます。
全壁の左右6pxは同じ12px柱を中央で分けたものです。各部品の左端=柱の右半分、右端=柱の左半分。隣接時に計12pxで1本となります。重ね描画や柱の追加は不要です。
途中で絵を圧縮したり、32px以上の部品を単なる細い壁として切り取ったりしないでください。

## 帯・角
edge_left 16×128 / edge_right 16×64 / edge_bottom 128×24。
leftは左壁マスの右16px、rightは右壁マスの左16px、bottomは下壁マスの上24px。
位相は従来通り：bottom h=x%4、left v=y%4、right v=y%2。
edge_fit/の対応する位相のPNGを使用します。assets/内のcorner_bottom_left/right、upper_left/rightはh0/v0の代表です。
右下は右側の原画を使った専用品で、左下の反転ではありません。
- outer_floor_nw：上と左が床。32×32。右側の帯edge_right(v=y%2)を使用。
- outer_floor_ne：上と右が床。32×32。左側の帯edge_left(v=y%4)を使用。
- outer_floor_sw/se：正面壁が受け持つため収録しません。
- corner_bottom_left：24×24、マス内(8,0)。斜めだけ床となる左下角。
- corner_bottom_right：24×24、マス内(0,0)。斜めだけ床となる右下角。
- upper_left/right：16×24、上24pxを置換。マス内left=(16,0)、right=(0,0)。
manifest.assetsのtile_offsetを参照してください。

## 終端（v5方式）
- end_vertical_left_vN__wall_*.png：16×24、マス内(16,8)。上8pxは従来の帯。
  下に接する壁の右端16pxに合わせて選択。
- end_vertical_right_vN__wall_*.png：16×24、マス内(0,8)。下の壁の左端16pxに合わせて選択。
- それぞれ上20行は元の帯そのまま、下4行で下の壁の上端へ接続します。最下行は壁y=0とピクセル一致。
- end_bottom_left_hN：24×24、マス内(0,0)。end_bottom_right_hN：24×24、マス内(8,0)。残り8pxは従来の帯。
  元の帯を使用し、外側1列だけ処理。色を暗くしていません。
該当する壁や位相が見つからない場合は通常の帯で描画し、例外を出さないでください。

## manifestの型
assetsは配列。wall_end_lookupも配列です。regionやphaseなどの設定オブジェクトを画像配列として走査しないでください。
個々のPNGはfile・size・kind・必要な位相/配置とSHA256を持ちます。

## 階の設定・B案
対象は26〜29階。30階のボス部屋は変更しません。全4階は同じ素材・明るさです。地下の遺跡の30%減光は引き継ぎません。
部屋間の壁厚を確保するB案に合わせた通常の高さ96pxの壁です。薄い壁専用素材は今回含めません。B案・周回ルートの地図生成調整とは分離して素材を読み込んでください。素材導入のために地図生成を再変更しないでください。
背景は暗い単色。通路1マス。既存の攻撃予告・探索済み/視界外の暗さ処理は維持します。
床は灰紫の石畳1種類。封印紋と紫の光は壁に描き込んであり、通行・ダメージなどの効果はありません。承認図の床中央の大きな封印紋は本セットでは省略し、床の視認性を優先しています。

## 確認
納品側：PNG読込、サイズ、共通6px柱、縦終端最下行と壁上端の一致を確認済み。
ゲーム側：幅390、大小の部屋、1マス通路、奇数壁、曲がり角、壁に接する各終端、赤い攻撃予告を確認してください。
幅390の代表画像を1枚と階全体の画像を1枚提示。ゲーム内の見た目・当たり判定は納品側では検証していません。
デザイン変更が必要でなければ小さな接続調整は実装側で対応可能。絵を無地化・大幅に変形する前に相談してください。

## 制作
内蔵imagegenで原画を生成。指定寸法への切り出し・縮小・共通柱の合成・帯位相別の接続処理を実施。
元の承認図の封印の最深部から帯と左右別の角を抽出。壁の紋様は縦横比を維持し、周囲に同じ原画の石造部分を組み合わせて指定幅へ調整。
