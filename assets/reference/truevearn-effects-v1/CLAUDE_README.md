# 真大魔王バーン 素材 v1

## 今回の確定指示
- 魔界の炎の輪・滅びの炎・天地の掌は削除。復活させない。
- ゲーム画面の技の表示は「カラミティエンド」「カラミティウォール」「天地魔闘の構え」など技名のみ。技の説明文は表示しない。必要な範囲予告は残す。
- 天地魔闘の構え中は専用ポーズに差し替える。「構」の文字表示は削除する。
- 構え終了・反撃終了・撃破・ロード時に正しいポーズへ戻す。
- 今回の素材取り込みを理由に、威力・頻度・継続ターン・カウンター条件を変更、確定しない。

## ファイル
各エフェクト: 00.png〜03.png は256×256 RGBA透過、sheet.pngは1024×256の横4コマ。
source.pngは生成原寸。ゲームには分割済みPNGかsheet.pngを使う。
truevearn_stance/stance_96.png と stance_192.png は構えの静止ポーズ。キャラの動作コマ4枚ではない。
preview_white.pngは白背景での確認用。ゲーム素材には使わない。
manifest.jsonにサイズと初期アンカーを記載。

## 再生案（戦闘仕様ではなく演出案）
- エンド:00→01→02→03（上→右→下→左）。周囲1マスに見える描画サイズに合わせる。
- ウォール:00→01→02→03（小→中→大→消散）。実際の周囲3マス予告を変えず、その範囲に合わせて外へ広がるよう配置。素材は円形の波を描いたものなので、正方形の当たり判定と形が完全一致するわけではない。四角の範囲予告は残す。
- 天地魔闘:構え中は専用キャラ＋00の控えめな光。反撃時に01→02→03。構え表示と反撃のタイミングは既存ロジックに従う。
- 仮の再生時間は各コマ80〜120ms程度から目視調整可。これは承認済み戦闘ターン数ではない。
- アニメーションで命中・反撃判定を増やさない。描画とゲーム処理を分離する。

## 組み込み確認
PNGの透明背景とZIP整合性は確認済み。実際のゲーム上での大きさ・位置・再生は未検証。
画像生成素材なので、フレーム間の中心と光の大きさは厳密な同一形状ではない。個別に自動トリミングしない。ボスの位置を固定し白床上でプレビューして必要なら描画オフセットを調整する。
構えポーズは既存待機画像の本体高さに合わせる。足元を同じマスに固定し、当たり判定は1マスのまま。
既存のコード描画と新しいPNGを重ねて二重表示しない。
スマホ幅360/390/430で、技名・ポーズ・予告・発動・解除を確認し動画で報告する。
