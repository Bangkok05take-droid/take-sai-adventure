# 真魔剛竜剣＋ドラゴニックオーラの盾：青い斬撃

参考画像の鋭い弧と流れる光の尾を取り入れたv2です。青白い気の刃が「バシュン」と右へ飛ぶエフェクト素材です。雷の枝分かれや炎ではなく、三日月の刃と短い光の尾で表現しています。

## 納品
- assets/launch/：3コマ
- assets/wave/：3コマ
- assets/hit/：4コマ
- slash_*_strip.png：横並びの確認用ストリップ
- manifest.json：順序、アンカー、試写用時間
- preview.gif：提供されたたけの立ち絵と仮のグリッド・標的を使った模式的な見本。実ゲーム画面ではありません。

## 配置
全PNGは64×64pxのRGBA透過。アンカーは(32,32)。右向きのみ。等倍・画像補間なしで使用。8方向はアンカー中心にゲーム側で回転してください。45度回転時も余白を確保しています。個別コマのトリミングや自動中央寄せは行っていません。

## ゲーム仕様（変更なし）
1マス32pxのターン制。通常攻撃時に正面2マス先まで飛翔。1マス目の敵を貫通して2マス目の敵にも命中（最大2体）。壁や角の向こうには届きません。当たり判定はゲームのマス判定のみで決定し、画像の輪郭・大きさは使いません。命中演出は実際に命中した各マス中心で再生します。手前の命中で飛翔を停止しません。

## 試写時間
各コマ30ms。launch90ms→wave90ms→hit120ms、計300msの仮設定。GIFの最後の700msは繰り返し確認用の休止です。確定値ではありません。手前の標的の命中は飛翔と重ねています。ターン処理を遅延・変更しない表示専用演出として組み込んでください。

## 作り方
画像生成で透過の4列×4行スプライト原画を作成。上段にlaunch3コマ、2段目にwave3コマ、3段目にhit4コマを配置。固定セルで分割し、全コマを共通の44×44pxへニアレストネイバー縮小、64×64pxの(10,10)へ配置しました。位置や大きさのコマ別補正はしていません。生成原画に由来する半透明の発光を保持しています。

生成指示：右向きの青白い三日月形の気の刃、白・水色・銀と少量の金、飛翔の尾は左へ、雷・炎・文字・背景なし。発射3、飛翔3、命中4コマ。固定中心と透明余白を維持。
