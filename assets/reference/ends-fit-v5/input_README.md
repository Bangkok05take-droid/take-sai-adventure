# 帯の終わり（end_*）を作り直すための接続先（2026年10月26日）

ゲームで今使っているPNGを加工せずに入れています（ファイル名だけ元の素材の名前）。1マス＝32px、拡大・縮小なし。

## 中身
- ends_mismatch.png：edge_fit_v4 の end_* を置いた所の拡大（4倍）。4組あり、各組の左が今、右が部品あり。
  - 1組目：end_vertical_left（レンガ）。帯の途中に暗い切れ目が出た所。
  - 2・3組目：end_bottom（下の帯の終わり。レンガ）。帯より暗く浮いた所。
  - 4組目：corner_bottom_right（採用。比較用）。
- brick_walls/：レンガの正面の壁（brick_repair_v3 の wall_arch 128×96・wall_banner 64×96・wall_narrow 32×96）
- roots_walls/：木の根の正面の壁（roots_match_v1 の wall_roots 128×96・wall_shrine 96×96・wall_roots_right 128×96・wall_narrow 32×96）
- edges_brick/・edges_roots/：今の帯（edge_left 16×128・edge_right 16×64・edge_bottom 128×24）

## 正面の壁の並べ方
- 正面の壁は3マス（96px）の高さで、いちばん下を床との境目にそろえる。
- 横の並びは左の端から。レンガは アーチ（4マス）→旗（2マス）のくり返し、木の根は 根（4）→祠（3）→根（右）（4）のくり返し。入らない残りは、レンガは旗か細い壁、木の根は祠か細い壁。
- なので、並びの**左端の列は、たいていアーチ（木の根は wall_roots）の x=0〜31**。**右端の列は、最後に置かれた絵の右端の32px**（どの壁の絵にもなりうる）。

## どこにつながるか
1. **end_vertical_left**（部屋の左の壁の帯 edge_left の下の終わり。マスの右16px・下24px）
   - 置く所：部屋の左の壁に、左へ出る通路の口があるとき。その口の上の正面の壁の**すぐ上のマス**。
   - 下に続くもの：その正面の壁の並びの**右端の列の上端**（壁の絵の y=0 から。x は右端の32pxのうち右16px）。どの壁の絵の右端にもつながる。
2. **end_vertical_right**（部屋の右の壁の帯 edge_right の下の終わり。マスの左16px・下24px）
   - 置く所：部屋の右の壁に、右へ出る通路の口があるとき。その口の上の正面の壁のすぐ上のマス。
   - 下に続くもの：その並びの**左端の列の上端**（たいていアーチ / wall_roots の x=0〜15、y=0から）。
3. **end_bottom_left / end_bottom_right**（部屋の下の帯 edge_bottom の左・右の終わり。マスの上24px）
   - 置く所：下の帯が、となりのマスの正面の壁にぶつかって終わる所（となりの部屋や通路の口の上の壁）。
   - 横に続くもの：end_bottom_left は左どなりの正面の壁の**右端の列**、end_bottom_right は右どなりの壁の**左端の列**。どの段（上・中・下の32px）にも当たりうる。
   - 帯そのものは edge_bottom の明るさ・石目のまま、端だけ閉じる形を希望。
