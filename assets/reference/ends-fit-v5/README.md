# end_* 差し替え ends_fit_v5
対象：レンガ1〜3階、木の根4〜6階。終端4種類だけの差し替えです。採用済みの角・上角・outer_floor_nw/ne は変更しません。sw/se は同梱しません。

## 変更内容
横終端は元の edge_bottom の対応24pxを切り出し、最外端1列のみ隣の列で閉じています。23/24列の色・石目・影は元のピクセルと完全一致。生成した暗い石は使っていません。
縦終端は元の edge_left/right の下24pxのうち上20pxを維持。最下4pxを接続先の壁画像の上端4行から組み、底面の暗い影を置きません。下端RGBは接続先の壁の y=0 と一致させ、接続帯自体は不透明です。壁素材の元の透明度は変更していません。

## Claudeへの指示
1. レンガから確認し、その後木の根へ。同梱の正面壁と帯は参照用です。元画像を上書きする必要はありません。今回差し替えるのはend_*のみ。
2. end_vertical_left: マス右16px・下24px、offset(16,8)。上8pxは既存edge_left。vはy%4。下の壁の実際の画像名を選び、画像右端16pxにつながる差分を使用。
3. end_vertical_right: マス左16px・下24px、offset(0,8)。上8pxは既存edge_right。vはy%2。下の壁の実際の画像名を選び、画像左端16pxにつながる差分を使用。たいていwall_arch/wall_rootsですが固定せず、実際に置かれた画像を参照。
4. 壁画像別の差分は __wall_arch 等の接尾辞で指定。対応する差分がない壁は推測で別画像を使わず、現在の終端表示を維持してください。
5. end_bottom_left: offset(0,0)、24×24、残り右8pxは元の帯。end_bottom_right: offset(8,0)、24×24、残り左8pxは元の帯。h=x%4。二重描画せず該当範囲を置換。
6. 下の終端は接する正面壁が上・中・下段のいずれでも同じ帯の明るさを保ちます。壁の暗さに合わせて帯全体を暗くしないでください。
7. 不採用のv4終端のみ置換し、採用済みの6種類をそのまま維持。床・背景・攻撃予告・通行判定・探索・戦闘を変更しません。
8. connections_2x は原寸部品を組んだ後2倍表示した確認図。縦終端の各組は左=元の帯、右=v5。横終端は各壁画像の上中下段に接したv5単独見本。ゲーム画像ではありません。
9. 壁上端が部分透過のため、実ゲームの下地によって明るさが変わる可能性があります。黒い切れ目が残る場合は、部品の追加加工ではなく、元の壁上端の透過と下地の関係をまず確認し、該当画像を返してください。
10. すべての壁画像・位相・段でプレビューし、暗い切れ目や色の浮きが消えたことを確認してください。自然につながれば、既に承認されたレンガの補修として反映可能です。木の根は現時点の承認状況に従い、未承認ならプレビューに留めてください。報告は比較画像と判断点だけ簡潔に。
