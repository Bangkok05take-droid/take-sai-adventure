# 正面・天地魔闘の構え v2 差し替え指示

このZIPは構えキャラクターのみ。以前のtruevearn_effects_v1.zipの構え画像を、この正面版に置き換える。3技のエフェクトは変更しない。

## 実装
- truevearn_stance_front_192.pngを標準候補にし、必要なら384版を利用。同じ絵の解像度違いで、別コマではない。
- 正面のまま使用する。自動で斜め向きにしない。
- 今回の画像寸法や透明領域込みの高さを、既存96pxの画像とそのまま同一視しない。
- 通常時の頭の幅、顔から腰までの長さ、胴体の太さを基準に、構え画像専用の均等拡大率を合わせる。縦横別倍率で歪めない。
- 挙げた手や角まで含む全体を同じ枠に押し込めて縮小しない。必要な描画領域を広げる。
- manifestの足元アンカーは初期目安。通常ポーズと構えの靴底の接地点が同じマスの同じ高さになるよう最終調整する。
- 構え開始で専用画像へ切り替え、終了・反撃終了時に状態に応じて通常画像へ戻す。再読込でも正しい状態を表示する。
- 「構」の文字は出さない。技名「天地魔闘の構え」だけ表示。説明文不要。
- nearest-neighborで表示し、画像のスムージングを無効にする。
- 技の威力・頻度・範囲・判定・ターン、ボスの当たり判定は変更しない。
- 魔界の炎の輪・滅びの炎・天地の掌は削除したまま。

## 確認と報告
通常→構え→通常を同じ場所・同じ画面倍率で撮影。エフェクトなしの比較も用意し、頭と胴体が小さくならないこと、足が浮かないこと、手や角が見切れないことを確認する。
スマホ幅360/390/430で確認し、比較画像と短い動画を返す。
元の通常ポーズ原寸と現在の描画設定がChatGPT側にないため、通常時とのサイズ一致はまだ検証できていない。体格差が倍率だけで解決できない場合は、通常ポーズ原寸PNGと比較画像を返す。
