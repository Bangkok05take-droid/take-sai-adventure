## 追加シートの読み方
上から4段、各4セルを想定した原画です。
1段目：左2つが床、右2つが壁上面。
2段目：左側／右側／上側／下側の壁を想定した直線の縁。
3段目：外角4方向。
4段目：内角4方向。
左右等の名称は「壁の塊がある側」を指します。描画エンジンのタイル名とは照合してから対応させてください。
原画のセル間余白や形状は正確な寸法テンプレートではありません。

- 完成したシームレスタイルではありません。切り出し・目地や縁の接続・明るさ・32pxでの視認性は未検証です。
