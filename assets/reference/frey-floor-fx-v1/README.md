# フレイザード 床攻撃エフェクト v1

承認済みの演出案を元にした氷柱・火柱の透過PNG素材です。実ゲームへの組み込み・検証は未実施です。

## 確定している見た目
- 氷：亀裂→小さな氷→突き上げ→大きな氷柱→砕ける→消える。同じ攻撃範囲内で一斉に発動する案。
- 炎：小さな発光→立ち上がり→強い噴出→火柱→減衰→火の粉。各マスに同じ単発素材を置き、開始時間をずらすことでフレイザード側から対象方向へ波を作る案。
- 範囲の形・広さは現在のゲームデータに従う。見本の3×3を新しい固定範囲として実装しない。
- 炎の進む方向は攻撃確定時の向きに固定。演出中に移動したプレイヤーを追尾する仕様を追加しない。

## 配置
接地点アンカーは各64×64内の(32,48)。対象マスの中央に合わせるなら、描画左上は(tileX*32-16, tileY*32-32)。カメラ座標の変換はゲーム既存方式に従う。
氷柱や炎の高さは隣接マスの上に見えるが、ダメージ範囲を画像の外接矩形から作らない。攻撃範囲は既存マス集合を使用する。
足元の亀裂や噴出から立体部分までを1枚にまとめた素材。キャラクターと重なる際の描画順はプレビューで検討。攻撃範囲の境界とカウントの数字は視認性を優先する。
通常のアルファ合成を基本とし、加算合成は必須にしない。拡大時は最近傍補間。フレーム間で自動トリミングや個別の大きさ変更をしない。
