# クロコダイン登場ムービー：実装依頼

## 素材と対象
- assets/movies/crocodine-intro.mp4：約10秒、720×1280、24fps、H.264映像＋AAC音声。提供動画を再エンコードせずfaststart化しています。
- assets/movies/crocodine-poster.jpg：再生準備中の表示用の先頭フレーム。
- このZIPは素材と指示のみ。ゲームのコード変更・実機検証は未実施です。
- クロコダインのみ対象。名前の表示文字列だけでなく既存の安定したボスIDで判定。他ボスのムービーや階層は変更しない。

## 発動タイミング
今回の指定は「クロコダインのボスの間に到着した際」。実装はボス部屋内部への初回入室時とする。ボス階に下りた瞬間や通路での接近では流さない。
既存の実際の部屋領域判定・戦闘開始処理を調べ、その入口に演出を挿入する。階層番号は推測せず最新設定を維持する。

## 状態と進行
1. 初回入室でダッシュ・自動足踏み・押しっぱなし・予約入力を停止する。
2. ゲームのターン、敵AI、攻撃、時間経過する戦闘処理を止め、入力をムービー専用に切り替える。装飾描画は必要なら継続可能。
3. ムービーを表示する。ボスは中央の有効床で待機、HPや位置は再初期化しない。
4. 動画終了・スキップ・読込失敗のどの場合も同じ一度限りの終了処理へ合流する。
5. 画面を戻し、既存の戦闘開始処理を一度だけ実行。ボスHP表示とボスBGMを開始し、操作を戻す。
ムービー終了そのものをターン消費に数えない。入室移動のターンを二重処理しない。終了処理やAI開始をended/error/skipから重複実行しない。

## 再生UI
ゲーム画面内の最前面オーバーレイとしてvideo要素を表示。縦横比9:16、object-fit:contain、上下左右は黒。縦動画の頭や斧、足を切らない。横画面でもcontainを維持。
playsinlineを設定し、loopは無効。ネイティブ全画面は必須にしない。準備中はposterを表示。
大きく押しやすい「スキップ」を常時表示し、スマホのsafe-area内に置く。背後のゲームへタッチ・キーが伝わらないようにする。
play()の拒否（音付き自動再生制限）は「タップして再生」と「スキップ」を表示し、ユーザー操作でplay()を再試行。無音に勝手に切り替えて見終わった扱いにしない。
動画ファイルの404/デコードエラーは短い案内を出し、操作を止めたままにせず終了処理へ進む。通信待機中もスキップ可能にし、読込や途中停止の長時間継続時には再試行/スキップを案内する。正常な約10秒再生を固定タイマーで途中終了させない。
アプリを背景にしたら動画を一時停止し、戻ったら必要に応じタップ再開を案内。背景で戦闘が進まないこと。

## 音
音声トラックがあるため、再生中は通常BGMを一時停止またはミュートして混ざらないようにする。既存の全体音量・ミュート設定を反映し、強制的に音を出さない。終了/スキップ後はボスBGMへ切り替える。videoを停止・破棄し、二重再生や残留音が起きないようにする。

## セーブ・再入室
既存セーブ形式に沿って、当該ボス戦の導入演出状態を追加する。新規プレイでは未開始。終了/スキップ後は完了として保存し、退室・再入室で再生しない。
再生中にリロードされた場合は既存のボス戦状態を維持して安全に再開できるようにする。「再生中」だけ残ってゲームが固まることを防ぐ。再開時に動画をやり直すかスキップ可能にする方針をコード内で明示。
旧セーブで既に戦闘中・撃破済みなら導入を挿入せずその状態を維持する。ボスHP・報酬・アイテム・資金をリセットしない。既存の周回/ボス再挑戦がある場合は、その遭遇単位の規則に合わせる。勝手に周回機能を追加しない。
ボスの部屋内移動制限を維持し、演出を理由に通路へ出たり入口を封鎖したりしない。

## 配置・配信
既存のアセット配置規則に合わせて動画とposterをコピーし、リポジトリのサブパスを含む公開先でURLが解決することを確認。ブラウザが直接取得できないGit LFSポインタだけの配信にしない。
動画をゲーム起動時の必須一括ロードに含めない。ボス階の接近時などに必要最小限の準備を行い、動画の遅延で通常のゲーム起動を阻害しない。

## 検証・報告
初回入室、再入室、スキップ連打、終了直前のスキップ、音付き再生拒否、ミュート、404、低速回線、背景復帰、セーブ再開、既存の戦闘中セーブ、撃破済みセーブを確認する。未確認のものは明記。
Androidの縦画面で映像が切れず、動画中に敵が動かず、終了後に一度だけ戦闘が開始し、操作が戻ることを確認。
実装した発動条件と動画の配置先、動作結果、未確認事項を報告。いつものブランチへコミットして通常のプッシュをお願いします。
