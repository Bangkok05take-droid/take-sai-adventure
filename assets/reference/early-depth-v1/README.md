# レンガの回廊・木の根の遺跡：奥行き素材 v1

## 最新の指定
レンガの回廊1〜3階、木の根の遺跡4〜6階だけに適用。各フォルダの approved_concept.png がユーザー承認の完成イメージ。原画の部屋形状に地形を変更する指示ではない。従来の壁上面を暗くした背景案は採用しない。

木の根の遺跡の外壁は「苔むした石造の外壁に根が絡む」方向で確定。土だけの崖にしない。左右の側面は今回作成対象外で、実際の画面を見て必要になったら128×384の左右素材を依頼する。

## ファイル構成
- assets/background.png：512×512、不透過。ゲームでは128×128（4×4マス）。自然の岩盤／土と根で、壁上面とは違う柄。
- assets/foundation_wall.png：256×384、不透過の正面石積み。ゲームでは64×96（2×3マス）。左右に並べる基本外壁。下端の透明フェードは描画側で付ける。
- assets/support_pillar.png：高さ512pxの透過PNG。縦横比を維持して高さ128px（4マス）で描画。上中央が接続位置。
- assets/optional_*：先に制作した旗・松明／根・ランタンの透過装飾。任意。まず必須3点でプレビューし、追加装飾はその後。
- source/：生成原寸と部品シート。シートの外壁は枠や柱が付いているため横並べの基本外壁には使わず、assets/foundation_wall.pngを使う。
- manifest.json：寸法、切り出し範囲、配置基準。

## 接続とサイズ
画像生成では背景の上下左右・外壁の左右接続を指定して制作したが、単純反復の完全なピクセル一致は保証しない。必ずゲーム実寸で2×2背景・3枚横並べ壁を先に確認。縦線が見える場合は、背景を列ごと左右反転・行ごと上下反転、外壁を1枚おき左右反転で並べる方法なら接続端の色と形を一致させられる。反転で対称模様が目立つ場合は画像を返して修正依頼する。継ぎ目を隠すために柱を2マスごとに増やさない。
床の明度は既存の読みやすさを維持。背景は素材自体が暗いため一律60%減光を重ねず、実画面で調整する。

## 描画指示
地下の遺跡の奥行き表示と同じ仕組みを地域ごとの素材で再利用する。
1. 自然の背景を地図座標に固定し最背面へ。背景の配置は未探索地形と無関係。
2. 探索済みで描画してよい床外周に限って、下方向へ外壁を伸ばす。画面下向きの辺が主対象。左右側面は既存の短い影で暫定対応し、正面壁を90度回転しない。
3. 外壁の上端を床の端へ合わせ、支柱の頭を同じ高さへ。外壁3マス、支柱4マスを初期値にする。柱は3〜5マス程度の間隔から調整。
4. 背景→外壁・支柱→既存地形→道具・キャラクター・予告の順。すでに見えている隣の部屋や通路を外壁や根で覆わない。
5. 未探索地形に応じて支柱の位置や外壁の長さを変えない。既知地形が同じなら、隠れた通路がある場合とない場合で装飾の表示も同じにする。
6. 地図外の背景も自然につなぎ、境界の四角い明暗差は作らない。探索済みで今は視界外の地形の既存の暗さは維持。
7. 旗・火・根は壁側へ置き、歩ける床・敵・アイテム・赤い予告を隠さない。入口に見えるアーチは実際の通路以外に置かない。支える外壁の下のアーチ表現は装飾であり通行可能にはしない。

## 変更しないものと確認
地形、通行判定、視界ルール、数値、物語、階数、ほかの地域、ボス部屋は変更しない。初版は静止画で十分。
幅360・390・430、部屋、1マス通路、上下に隣接する部屋、地図外、探索済み視界外を確認。画像を使って承認イメージにどの程度近づいたか見せる。完成イメージはアート目標であり、全ランダム地形で同じ構図が得られることを保証するものではない。
本番切替はゲーム内プレビュー確認後。報告は画像、判断が必要な点、次にすることだけ短く。
