通常階の追加背景・下へ伸びる外壁・長い支柱は不採用。部屋の外は暗い単色のまま。
床は各地域の floor.png 1種類で部屋・通路とも統一する。原画上段の別セルを混ぜない。
壁はまず wall_front / wall_narrow / wall_top と細い縁のみで構成。大型装飾・柱の重ね置きはしない。

既存の探索済み・視界外の暗転は維持する。素材の色差と視界処理を混同しない。

## 内容と寸法
assetsは切り出し済みPNG。manifestに原画座標と表示目安を記載。
- floor.png:256×256→64×64。2×2ゲームマス。壁際・通路でも同じ地図座標の模様を継続し、通路だけ1マスに押し縮めない。
- wall_top.png:256×256→64×64。暗い壁の上面。未探索の背景全面には敷かない。
- wall_front.png:256×256→64×64。2マス幅×2マス高。通常の正面壁として使用し、追加の下向き外壁として扱わない。
- wall_narrow.png:128×256→32×64。奇数長末尾・単独1マス壁用の無装飾部分。左右に重い柱を詰め込まない。
- rim_vertical_strip.png:12×128→3×32。
- rim_horizontal_strip.png:128×12→32×3。
  縁は壁領域に配置し、通路幅を削らない。方向に合わせて反転可能。内外角は既存の正しい角判定で細い帯を結合し、交差部を二重描画しない。専用の完成角画像は今回含まれない。
- wall_pilaster_optional.png / wall_emblem_optional.png:256×256→64×64。壁面に収まる浅い装飾の候補。初回は未使用。装飾採用時は基本壁に重ねず、その壁モジュール自体を差し替える。
source_atlas.pngは原画保存用。4×4セル風だが実寸1254×1254で、下段には指示どおりでないL字があるため、下段セルをそのまま角セットとして使わない。
repeat_preview.pngは同一床・同一壁の繰り返し確認画像。ゲーム画面でも承認済み完成図でもない。
