# レンガの回廊 補修素材 v3
対象：1〜3階。brick_match_v2 の壁3種を置換し、角・縁端12点を追加します。床は同梱せず、現在採用した1種類を維持します。

## Claudeへの指示
- まずプレビューで確認してください。赤い旗・アーチ・灯りを残し、別の柱や飾りは重ねません。
- wall_arch 128×96、wall_banner 64×96、wall_narrow 32×96。高さ96px、原画1マス=32px。下端を床境界に合わせます。
- 左端6pxと右端6pxは同じ柱の左右半分です。隣接画像を重ねず、そのまま横につないで柱1本にします。端で柱を追加して二重にしないでください。
- 旗の切れ端を除き、3種類の端を共通部品で組み直しています。内部の石目・陰影は完全一致ではありません。ゲーム画面で横連結を確認してください。
- 外角は outer_nw/ne/sw/se。名前はL字の突き出す角位置を表します。upper_left/right は上端接続、lower_left/right は部屋の下角。end_* は通路開口の縁の終端です。
- 角素材は依頼寸法に切り出した候補です。既存の縁の幅と接続基準に合わせ、床を覆わない範囲で配置します。合わない部品は無理に引き伸ばさず、その場所だけ現行描画を維持し、必要寸法を返してください。
- 自分の描画領域内でクリップし、隣室・通路・キャラクター・攻撃予告を覆わないこと。
- 床の色は変えず、赤い攻撃予告の塗りと輪郭を強くして見やすくしてください。
- 背景は暗い単色。下へ伸びる外壁・支柱は復活させません。地形・通行判定・探索・戦闘ロジックは変更しません。
- 奇数長の壁、1マス通路、上下左右の角、通路開口、隣室、アイテムと予告の重なりを確認してください。通常倍率・幅390の画像で前後比較してください。
- 同じ見た目の範囲で自然につながることを確認できれば、既に許可された本番反映へ進めてください。問題が残る部品は保留し、判断が必要な点だけ短く報告してください。

## 同梱物と確認範囲
assets は配置用15点、source_atlas は新規生成原画、approved_reference は既存の承認図、assembly_preview は実PNGを並べたローカル確認図です。ゲームのスクリーンショットではありません。
PNGサイズ・読込・ZIP整合性・共通柱の半分の連結を確認。実ゲームへの適合はClaude側で確認が必要です。
背景透過は画像生成ツールで作成。部品はその画像を切り出し・縮小し、柱の共通部分を組み合わせています。
