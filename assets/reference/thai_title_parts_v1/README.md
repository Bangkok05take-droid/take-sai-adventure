# タイの大冒険 タイトル素材 v1

## 内容
- title_bg.png：1024×1536、背景のみ。人物・文字・ボタンなし。
- title_logo.png：1200×480、RGBA透過。題名「タイの大冒険」は横一列、副題「― 封印の遺跡 ―」を含みます。
- reference/approved_layout.png：承認済みの配置見本。ゲーム背景として直接使わないでください（ボタン文字が焼き込まれています）。

背景とロゴは、承認図を作る際に使った分離済みの元画像から用意しました。背景はそのまま、ロゴのみ幅1200pxへ縮小しています。完成見本は画像生成で合成したため、元画像の再合成と細部までピクセル一致するものではありません。新しいデザインへの変更・再生成はしていません。

## 組み立て
1. 背景を表示。中央の扉を中心に配置。背景四辺の景色は少量のトリミングが可能です。画像自体を引き伸ばして縦横比を変えないでください。
2. ロゴを別レイヤーとして上部中央に配置。1024×1536の基準画面で、おおむね x=60,y=20,width=904,height=362。装飾込みの画像全体を表示してください。
3. 既存のゲーム側ボタンを再利用して色調整。文字はゲーム側のテキストで表示します。新しいボタン枠素材は含みません。
4. 基準画面で、続きからは x=185,y=880,w=654,h=133、はじめからは x=195,y=1020,w=634,h=117、小ボタンは左 x=205,y=1145,w=300,h=82、右 x=520,y=1145,w=300,h=82 が配置目安です。実際の枠の透明余白を考慮して見本に合わせてください。
5. 青い扉の紋章をメニューで隠さないようにし、メニューの下には石畳の余白を残してください。

## 端末対応
- 背景のトリミングとUI配置は別管理。背景に合わせてボタンまで切らないこと。
- 幅360/390/430と高さの違う端末で、ロゴ全文・ボタン・タップ範囲を確認してください。
- 極端な縦横比では背景の拡大を抑え、余白色で補って扉を守ってください。安全領域と最低44CSS px程度のタップ高さを確保。
- ボタン画像に文字を焼き込まないこと。音のオン／オフは実際の状態と一致させてください。
- 既存セーブ・保存キー・各ボタンの動作は維持。名前入力機能は今回の対象外です。
