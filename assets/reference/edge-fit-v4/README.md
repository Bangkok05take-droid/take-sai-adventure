# 縁・角 補修 edge_fit_v4
対象はレンガ1〜3階と木の根4〜6階。入力ZIPの縁PNGを原寸のまま使用し、接続端を元のピクセルで保持しています。元の素材は original/ に加工せず同梱。

## 前回からの変更
出っ張った角だけ32×32へ変更。24×24内に高さ24pxの横帯を入れると、L字の抜けがなくなるためです。32×32で縦16px・横24pxを確保し、残る16×8pxを透過しています。ゲームの1マスには収まります。
上端と左右終端は16×24、下終端は24×24。下角は左右別々の24×24で、右下は左下の反転ではありません。木の根も同じ構造です。

## Claudeへの実装指示
1. 壁・床・背景・予告の現在の設定を維持。今回は角と縁の端だけ差し替えてプレビューします。brick_repair_v3 の不採用角は使いません。
2. assets/ は位相0の代表です。元の帯がマス行・列で32pxずつ切り替わるため、variants/ に対応位相を同梱。h0〜3 は edge_bottom の x=0,32,64,96、v は左右帯の y=32×位相。現在のレンダラーで実際に選んだ位相を使い、未知の式を推測で変更しないでください。
3. outer_floor_nw は上と左が床、ne は上と右が床。マス左上に32×32で配置し、既存の縁2本に重ねず置換。sw/se は下側に床がある場合の対称的な形の候補ですが、下側の床境界を正面壁が担当する場所では配置しないでください。四方向を無条件に当てはめないこと。
4. upper_left/right は左右の縁の上24pxを置換し、下に同位相の縁の残りを続けます。end_vertical_left/right は縁の下24pxを置換し、上8pxを元の縁のまま残します。
5. end_bottom_left は横帯の左24pxを置換、右8pxを残す。end_bottom_right は右24pxを置換、左8pxを残す。通路開口・隣接正面壁で帯が終了する場合にだけ使います。
6. corner_bottom_left/right は斜めだけが床の部屋下角用。左は壁マス右上(8,0)、右は左上(0,0)。元の角を置換し二重描画しないでください。下角の横縦の接続が交わる4pxは縦帯優先です。この部分は実画面で確認してください。
7. 左右の名称は部屋の左壁・右壁の意味です。床の位置から使用する edge_left/right を決めます。manifest に矩形・位相・配置情報を記載しています。
8. 外角の透明部分に黒色を塗らず、元の地形を残します。画像も帯も拡大縮小せず原寸。通行・探索・地形・戦闘は変更しません。
9. connections_2x.png は原寸素材を組んだ後、確認用に2倍表示した見本。青枠が新部品です。ゲーム画像ではありません。帯は位相0例のため、実マップでは隣接マスの位相による石目も確認してください。
10. まずレンガで実画面を確認し、同じ処理を木の根へ適用。上角・下角・出っ張り・通路開口・隣室を幅390で確認。自然につながる部品だけ採用してください。木の根の本番反映はまだ承認待ちのためプレビューに留めます。

## 検証と限界
元の縁を無変更コピーしSHA256を記録。外角の透過マスク・寸法・接続端4pxの元画像一致、PNG読込、ZIP整合性を確認しました。
生成した石の内側を、元の帯と組み合わせた部品です。色・石目の自然さと既存壁上端との接続は実ゲームでの確認が必要です。すべての接続が無条件で完成したとは扱わないでください。

制作: built-in imagegenで茶色/苔色の左右別の石の端を生成し、元画像の帯を原寸で切り出して配置。原画と入力データを同梱。
