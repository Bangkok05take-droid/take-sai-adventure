# 画像素材

- `title-characters.png`：見本イラスト（人物・人物名・題字・ドット絵一覧を含む元画像。変更しない）。
- `title-chars.webp`：タイトル画面の主役の人物。元画像から `node tests/make-title-art.js` で作る。
  - 紙の色の部分を外周から塗りつぶして透明にする（人物の輪郭線で止まる）。題字・名札・飾りは消し、たけとサイだけを残す。
  - 縦横比を保って表示し、引き伸ばさない。後ろの夕暮れの遺跡・水辺・石のテラスは `js/ui.js` がキャンバスに描く。
- `title-art.jpg`：紙の背景つきの切り出し（透過画像を表示できないときの予備。同じスクリプトで作る）。
- `logo.png`：タイトルロゴ「たけとサイの／大冒険」と紋章（剣・宝珠・アユタヤの塔）。`node tests/make-logo.js` でSVGから作る。
  - 文字は Google Fonts の「Dela Gothic One」（SIL Open Font License）。作るときだけ取得し、ゲームはPNGだけを使う。

## 見本から作った素材（実装用）
見本の中の**ドット絵の部分だけ**を使う。文字・飾り枠・背景を含む四角い切り抜きは使わない。
見本のドット絵は1ドットが約4〜5ピクセルで描かれているので、格子を推定して**1ドット＝1ピクセルに戻す**（拡大でぼやけた絵は使わない）。
紙・濃い青緑の背景は外周から塗りつぶして透明にする（輪郭線で止まる。足元の影の残りも消す）。

- `chars/`（`python3 tools/extract-art.py` で作る）：人物の透過PNG。
  - **基準：キャンバス横52×縦64、1ドット＝1ピクセル、足の裏は y=62、足元の中央が x=26**（全員共通）。
  - 背丈：たけ・サイ・村の4人は約47〜49ドット、ヤナイは約61ドット（記念像・回想で使う）。
  - 向き：たけ・サイ・ヤナイは正面/横/背面（横は見本どおり左向き。右向きは左右反転）。コイ・モッ・ワーン・ティウは正面/背面。
  - ゲームでは1マス32ドットに対して、人物は足元をマスの下端にそろえて描く（頭は上のマスにかかる）。拡大は整数倍（村）またはダンジョンの縮尺。
- `items/`（`python3 tools/extract-items.py` で作る）：道具の透過PNG。
  - `list/`：一覧用 48×48（元の細かさのまま。道具画面では96×96に整数倍してから表示サイズへ）。
  - `floor/`：床に置いた状態用 32×32（縮めたあと1ドットの濃い輪郭を付け直し、暗い床でも形が分かるように）。
  - 剣・盾・巻物・薬草・素材の色違いは、見本の1つの形から色相を置きかえて作る（形は同じ）。
- 使う画像の一覧とキーは `js/assets.js`。読み込めない画像は、コードで描いたドット絵に自動で戻る。
