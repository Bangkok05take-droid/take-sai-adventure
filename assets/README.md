# 画像素材

- `title-characters.png`：見本イラスト（人物・人物名・題字・ドット絵一覧を含む元画像。変更しない）。
- `title-art.jpg`：タイトル画面で使う人物イラスト。元画像から `node tests/make-title-art.js` で作る。
  - 上段の人物だけを切り出す。下段のドット絵一覧と外枠は使わない。
  - 人物名の札・題字・四隅の飾りは、周りの紙の色で塗りつぶす。題字はHTMLの文字で出すので、二重にならない。
  - 拡大・縮小はしない。画面では縦横比を保ったまま全体を収め、金の額縁を付けて表示する。
  - 切り出す範囲と消す範囲は、スクリプトの `CROP` と `MASKS` で調整する。
- `title-art.jpg` が読めないときは、ゲーム用のドット絵（全身絵）でタイトルを描く。
- ゲーム内のドット絵（`js/sprites.js` の `drawTake` / `drawSai`）は、見本下段のドット絵に合わせて描いている。
